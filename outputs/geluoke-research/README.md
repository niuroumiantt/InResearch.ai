# 历史文章与研究材料

本目录保留既有文章、HTML、图片、SVG、来源、研究候选、历史提示词和检查回执，供展示与追溯。2026-10-11 文章写作、配图、制作和生产端发送职责统一归 [inews.today](https://github.com/niuroumiantt/inews.today/blob/main/docs/editorial/README.md)；本仓库的制作脚本已删除。

所有旧提纲、提示词、卡片模板、制作参数与检查结果均属于当时稿件的历史记录，不是新稿执行标准，也不证明旧数据当前有效。现行产品分别采用 [微信日报](https://github.com/niuroumiantt/inews.today/blob/main/docs/geluoke-daily-delivery.md)、[网站专栏](https://github.com/niuroumiantt/inews.today/blob/main/docs/columns.md)、[研究报告](https://github.com/niuroumiantt/inews.today/blob/main/docs/editorial/research-report.md)；首图风格不从这些旧稿继承。

保留的 `2026-10-09-us-datacenter-power/work/tools/acquire.py`、`research.py`、`visual_sources_v3.py` 仅供历史研究来源和身份追溯，不是文章制作入口或在运行任务。本目录原材料不自动取得正式采用资格；接收、阅读、C3与研究发布仍分开记录。

InResearch 的接收入口及阶段边界见 [研究接收协议](../../docs/local_reader/EDITORIAL_DELIVERY.md)。研究 UI 技术图册另按 CURRENT 的研究规范执行。
