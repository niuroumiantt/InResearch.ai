## 实施与验收边界

正式项目登记和raw来源资料并行显示，168条项目记载保留原文容量/阶段/角色/日期与来源；国家级落点是资料分布示意。每日发表、接收、容量观察与正式采用分别计量，未知运行数据不用零填充。前后端仅有界白名单投影，首页使用overview压缩接口、复用底图、新闻先展示后补登录态。

本地单测与浏览器截图属于受控验收，涉及新闻容量的夹具明确为测试输入。最终head CI、生产网站字节/接口/手机与冷加载验证分别登记；本地截图不证明已部署或真实今天完成量。缺失原件身份、完整全球布局、精确园区坐标与后续正式采用保持待补。
