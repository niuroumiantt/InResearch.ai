# 2026-10-02 行业总览交付

用户已采用首页重新承担市场规模、世界地图、玩家布局、项目机会与精选新闻的方向。当前规则见 framework/05_interface_system.md 与 06_acquisition.md；本页记录实现与本地验收范围。

## 已实现

- `/` 与 `/index.html` 为独立行业入口，原节点研究在 `/node.html`。七项导航、角色白名单、界面清单与替代登记同步。
- `/api/industry` 共用 IT 容量聚合；分期优先、未知不补零、设施功率不相加、组合记录不计入物理园区容量。公司是相关园区视图，不声称权益容量；筛选和详情列表可对账。
- 世界地图支持缩放、拖动、键盘选点，Microsoft / Meta 等主体切换；项目与市场详情保留来源、口径和预测标记。区域、参与关系、身份及已登记 AI 类型可筛选。
- 首页不渲染项目表格、完整线索；表格与时间线均点击进入。首页为全球规模大数字、地图、精选新闻、机会阶段图、四个主要玩家及区域机会图。
- 全球容量用汇丰报告的 2025 年约 95 GW IT 负载估算与 2030 年约 205 GW 预测，明确时间、出处与非当前投运普查；地图各容量卡标「样本」。
- 市场序列为已登记 Dell’Oro 全球年度 IT 资本开支，2026 起为预测；内部报告原件不暴露路径。首页运营收入和逐年投运曲线未编造。
- inews 编辑精选按 editorial_pick 筛选，可查看全部线索；公司按 actor 关联，地区与项目按人工或全名+actor 唯一匹配的 site_id 关联，自动匹配明示待核实。没有真实快照时显示未连接。
- reader 固定来源契约校验后的项目事件、租约及低置信度建设标题进入 acquisition/project-pipeline.json；跨七天窗口保留、文章/聚类去重、命名园区跨事件关联、按发布时间更新报道阶段、撤回恢复前一条有效消息；人工审核决定不被重复新闻覆盖。pipeline CLI 可复审、暂停、取消与关联已登记园区。acquisition.summary → reader 快照 → /api/news 传递限定公开字段。

## 验收范围

Python 测试覆盖分期与总量、组合排除、未知容量、公司/阶段下钻对账、非法筛选、匿名读取边界、市场预测、长期线索、聚类/撤回/复审、真实 import_news 到公开快照的集成路径。浏览器套件 industry 覆盖公司、地图、精选新闻、下钻、来源、键盘、手机及明暗；相关套件 datacenter_news / research_delivery / ui_skin / dashboard 覆盖原研究入口与共享外观。

本机使用 Playwright 1.62.1 驱动系统 `/usr/bin/chromium`；CI 保留现有固定浏览器安装方式。系统浏览器验证不代表已下载 CI 对应浏览器版本。测试数据仅在浏览器请求拦截或临时目录中，不写入真实新闻和项目库。

**[Codex 云开发环境]** 运行 Python 套件时不要导出网站运行根，测试自己创建隔离目录：

```bash
cd /workspace/InResearch.ai
env -u INRESEARCH_RUNTIME_ROOT PYTHONPATH=src python3 -m unittest discover -s tests/unit
python3 manage.py governance --check
python3 manage.py validate --strict
python3 manage.py registry
```

初版验证：1,645 项 Python 测试和五组浏览器套件通过。二次修订增加全球基准口径、无首页表格、低置信度入池、园区自动关联与撤回恢复验收；二次修订结果：完整 1,649 项 Python 测试通过；最终标题容量提取补充后，14 项行业/线索测试再通过。industry、datacenter_news、research_delivery、ui_skin、dashboard 浏览器套件通过，新闻先到的地图加载竞态已修复；治理检查、严格校验（0 warnings）与注册表检查通过。
