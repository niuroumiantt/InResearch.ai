# 最终逻辑与架构图（2026-09-28，第 8 步重画）

[ARCHITECTURE.svg](ARCHITECTURE.svg) 一张图：

- **目录（组织轴）**：数据中心 / 账本 / 爆炸图 / 采集 / 成果 / 管理 = 四问的全局视图；角色四种（admin、member、intern、公开只读 reader，服务端过滤）。
- **名词轴（一棵树）**：数据中心 → 五个系统（IT 展开四个子系统）→ 系统内按能量流链路 → 61 部件 + 软件 + 基型，六条站点权利并列；部件带尺度、建设阶段与兼容模块属性。研究图谱 3.0 由骨架生成，对象只有六种。
- **描述轴（五类变量）**：构成、运行、价格、时间、主体。正交，无先后。每个模型输入、每条目标行、每条登记（`node` + `variable_class`）都按此打标。
- **三级账**：成本、收入、回报，来自唯一的统一经济模型；一个账本页，四个视图，三种问法，三个校准锚。
- **数据轴（四段）**：采集（六队）→ 事实（登记表）→ 规则（骨架、因子树、模型、dashboard 规则）→ 视图（一个模板 + 五页）。四问就是四段倒序。
- **回路**：目标表由规则层生成，回写采集需求；节点页灰格与采集页目标行双向链接；派工按目标行 ID；delivered 只认 Git 内载体。

每个框都写了对应文件。生成物（目标表、dashboard 快照、图谱与问题表、登记表两列、清单）由命令重建并被 `--check` 与单元测试守住；规则表进评审，生成物不进。图下方列出 2026-09-28 起退役的词汇与轴，只在"退役什么"或历史快照里出现。
