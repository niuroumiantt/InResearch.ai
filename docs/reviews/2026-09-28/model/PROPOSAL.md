# 统一经济模型 v3 提案：以我们的骨架为底，吸收摩根士丹利、高盛与 SemiAnalysis 的三个角度

2026-09-28｜状态：**已采用**（三个决定 2026-09-28 确认；实施见 docs/DECISIONS.md 同日条目与 framework/05_interface_system.md「统一经济模型与账本」）。原提案正文保留如下。前提：用户已决定三个计算器只保留一个基准模型（基准里的数可变）。本稿回答两个问题：现在的 TCO 模型是不是最好的；怎样结合三家机构的方法把它优化成一个模型。外部材料只作对照与校准，不作为现行指令。

## 0. 一页结论

- 三家机构各自只回答一个问题。摩根士丹利回答"一座满配新代际的数据中心一年挣多少"（1GW GB300 账本，ROIC = NOPAT ÷ 资本开支）；高盛回答"要在这批资本开支上挣到 15% 回报，需要多少收入"（反算，带利用率爬坡与情景网格）；SemiAnalysis 回答"中国的数据中心到底有多少、在哪、谁在租、为什么便宜又快"（逐栋建筑的存量与制度差异）。三者都不是我们意义上的模型：它们没有部件、没有权利、没有采集链，也没有数据出处的状态。
- 我们的 TCO 模型在覆盖面上已经比三家都全：47 个输入五类打标、每个输入带证据状态、因子树连到 61 个部件与 6 条权利、逐年现金流与四本账。它不是最好的原因不在覆盖，而在三点：三个模型并存各自漂移；只会"正算"不会"反算"；把美国弗州一套制度当成唯一世界。
- 优化方向不是换骨架，是在现有骨架上加三个角度：高盛的反算与爬坡，摩根士丹利的账本口径作为唯一校准锚，SemiAnalysis 的制度参数（电力门槛还是芯片门槛、审批与配额、造价与租金的地区版本、BOT 持有方式）。结果是一个模型、一份输入表、三种问法、四本账输出。

## 1. 三家机构的方法拆解

| | 摩根士丹利《AI 指南》2026-09 | 高盛《Sizing the AI Economy》2026-09-24 | SemiAnalysis《China Datacenter Model》2026-09-25 |
|---|---|---|---|
| 问的问题 | 满配 1GW GB300 出租，年收入、NOPAT、ROIC | 六家超大规模厂商 2026–27 资本开支要多少 2028–30 收入才够 15% ROIC | 中国有多少数据中心，在哪，谁租，为何便宜与快 |
| 单位 | 每 GW | 每 GW，聚合到公司与行业 | 每栋楼，聚合到集群与国家 |
| 造价 | 按代际：GB300 390 亿/GW，IT 230、非 IT 160；表后自发电另加 30 亿 | 统一 424 亿/GW：服务器 57%、网络 29%、设施 13%；自下而上按芯片厂商每 GW 收入反推 42 → 35 亿 | 中国壳与机电造价是美国批发的一小部分；预制与国产化让造价持续下降 |
| 收入 | GPU 数 × 8,760 × 75% 利用率 × 8.5 美元 | 目标 ROIC 反推：NOPAT ÷ (1 − 21%) + 折旧 + 运营 = 收入；利用率 60/80/85% 逐年爬坡；每 GW 满负荷 11.4–11.7 亿 | 批发价 80 美元/kW·月被腰斩后的市场；批发上架率 >70%、零售 ~60% |
| 折旧与寿命 | IT 5 年、非 IT 15 年 | 算力 5 年（70%）、壳 15 年（30%） | 银行按 20 年设计寿命估值，集装箱残值低 |
| 运营 | 能源及其他 20 亿/GW·年 | 8.36 亿/GW·年（Epoch 基础上加 10% 通胀）+ 其他成本 | 电价：内蒙古约为一线城市一半 |
| 回报口径 | ROIC = NOPAT ÷ 总资本开支；三条货币化路径 31% / 46% / 25% 利润率 | ROIC = NOPAT ÷ 两年平均资本开支；情景网格 ROIC 0–30% × 造价 34–51 亿/GW | 成本收益率区间与柔佛重叠；BOT 下 IRR 由 8–10 年服务合同锁定 |
| 制度与时间 | 38GW 电力缺口；融资 3.21 万亿拆股权与五类信贷 | 资本开支先于投产两年；云积压 1.69 万亿对照 | 美国电力门槛（并网、变压器）vs 中国芯片门槛；100MW 12 个月交付，审批 3–6 个月；能耗配额是硬上限 |
| 敏感性 | 只对单价 7–10 美元 | 对 ROIC 阈值与造价/GW 双向 | 无（它是存量模型） |

三家共用同一条骨架公式，也就是我们因子树已经登记的：收入 = GPU 数 × 小时 × 利用率 × 单价；成本 = 电费 + 其他运营 + 折旧（分 IT 与非 IT）+ 税。差别只在四个口径：造价怎么拆、利用率是常数还是爬坡、回报的分母取什么、制度参数取哪个国家。

## 2. 我们现在的模型：全面，但有三个短板

**覆盖面比它们全的地方**

- 输入 47 个，每个带变量类（构成、运行、价格、时间、主体）与证据状态（用户给定 / 已有来源 / 作者假设），三家报告的输入都没有出处状态。
- 因子树把每个输入连到 61 个部件与 6 条站点权利，部件有自己的价格、供应商、交期；造价不是一个 424 亿的整数，而是变压器、冷机、光模块各自的价格与交期之和。三家都停在"服务器 57%、网络 29%"这一层。
- 逐年现金流：建设期、爬坡、电价与运营涨幅、IT 更新、退役；四本账把芯片厂商、壳层、算力层、模型层的利润分配算出来；GPU 抵押与项目债的杠杆回报。
- 采集链：每个输入背后有目标行、有队、有日历；报告的数字是一次性的，我们的是可更新的。

**三个短板**

1. 三个模型并存。同一个 PUE 在三处是 1.25、1.18、1.25，电价 0.08、0.10、0.08。读者看到三个答案。
2. 只会正算。给定输入算回报，不会像高盛那样给定目标回报反推需要的单价、利用率或造价；也没有利用率逐年爬坡（现有 ramp_year1/2 只用在成本侧现金流，收入侧是常数 75%）。
3. 单一制度。站点预设只有电价与地价之差，没有"电力门槛还是芯片门槛"这种决定建设周期、审批、造价与租金水平的制度参数；中国情景只是汇率换算。

## 3. 统一模型 v3 的设计

一个模型，一份输入表，三种问法，四本账输出。骨架不变：因子树 → 部件与权利 → 目标表；变的是引擎与页面。

### 3.1 一份输入表：按五类变量分组，每个数带出处

在现有 47 个输入上并入经济模型独有的 8 个（芯片毛利份额、token 吞吐与价格、变现份额、壳层杠杆与利率、算力杠杆与利率、残值份额），再加 v3 新增的 9 个：

| 变量类 | 新增输入 | 来源 |
|---|---|---|
| 构成 | 造价拆分方式：按代际（摩根士丹利 6 个代际表）或按部件（因子树自下而上求和） | 摩根士丹利 p22；bom.json |
| 运行 | 利用率爬坡：第 1、2、3 年及稳态（默认 60/80/85/85%） | 高盛 Exhibit 7 |
| 运行 | 上架类型：批发 / 零售（决定稳态利用率默认值） | SemiAnalysis |
| 价格 | 单价路径：现货 / 一年期 / 多年期 及年变动 | 已有 price_change，扩为三档 |
| 时间 | 制度门槛：电力门槛（并网排队年限进建设期）或芯片门槛（交期进建设期） | SemiAnalysis；site_rights grid / permits |
| 时间 | 审批期（月）与能耗配额上限（MW），作为站点权利的时间与构成类事实 | SemiAnalysis；site_rights permits |
| 主体 | 持有方式加 BOT：业主持地与壳，合作方持机电并按 8–10 年服务合同回收 | SemiAnalysis |
| 主体 | 承租人信用：合同期、担保方、递增，进壳层账本 | 已有 lease_term/escalator，加担保方字段 |
| 主体 | 目标回报：ROIC 阈值（默认 15%）与回报分母口径（总资本开支 / 平均年资本开支） | 高盛；摩根士丹利 |

地区不再是一个"站点预设"，而是一组制度参数的预设：美国弗州、美国得州、内蒙古、柔佛。每个预设的每个数都指向价格库序列或权利表。

### 3.2 一个引擎，三种问法

- **正算**：现有 TCO 引擎，输入 → 逐年现金流 → 平准化成本 → 四本账。收入侧改为利用率爬坡与单价路径。
- **反算**（高盛）：给定目标 ROIC，解出需要的单价、或利用率、或每 GW 收入；输出"每 GW 满负荷需要多少收入"这一个数，与高盛 11.6 亿/GW 直接对照。
- **情景网格**（高盛 + 摩根士丹利）：造价/GW × 单价 × 利用率 的三维表，每格一个 ROIC，标出摩根士丹利 31% 与高盛 15% 两个锚。

三种问法共用同一份输入与同一段代码，`knowledge/economics.py` 是唯一的 Python 参考实现，页面 JS 与它同一公式，单元测试以三家报告的数字为锚：摩根士丹利 229 亿 / 121 亿 / 31%，高盛 11.6 亿/GW 满负荷收入与 34.7% EBIT 利润率，我们自己的 2026-09-14 基准 11.68 亿总成本。

### 3.3 四本账与三个视图作为输出

页面只有账本 `ledger.html`：上半部分输入与情景（五类分组），下半部分四个结果视图：成本结构与平准化（原 TCO）、四本账（原经济模型）、单位成本每有效设备小时（原成本计算）、反算与情景网格（新）。`economics.html`、`tco.html`、`cost.html` 退役，地址由路由指向账本。根节点三级账改读这一个模型。

### 3.4 与骨架的连接

- 造价按部件求和时，每个部件的价格来自它的价格行（目标表 P.部件.price），缺的用代际表补并标"缺"。这样矩阵里价格列变绿一格，账本的造价就少一处假设。
- 时间类输入从权利表读：并网排队年限（grid）、审批期（permits）进建设期；变压器、燃机交期（部件时间列）进关键路径。这是"电力门槛"的具体形态。
- 中国情景的电价、造价、租金、上架率，登记为价格库序列（已有 cn-dc-power-price-*、cn-idc-capex-per-mw-gds、cn-colo-mrr-per-cabinet-vnet 等），不再是页面里的常数。

## 4. 与三家报告的对照会怎么读

做完之后，账本能直接回答三家各自的问题，并指出它们没说的：

- 对摩根士丹利：同一 1GW GB300 输入复现 31%；再把利用率改成爬坡、单价改成两年期 7.22 美元，看 ROIC 掉到哪里。
- 对高盛：同一造价 42.4 亿/GW 与 15% 阈值复现 11.6 亿/GW；再把造价换成我们按部件求和的数，看差多少、差在哪几个部件。
- 对 SemiAnalysis：内蒙古预设下的成本收益率与柔佛预设对照；把制度门槛从电力换成芯片，看建设期与回收期怎么变。
