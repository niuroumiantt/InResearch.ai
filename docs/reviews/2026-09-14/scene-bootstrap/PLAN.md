基线 e754944，702 个在册文件，现行 2026.09.13.11；上一批已发布并验证。file-plan.csv 覆盖全部基线文件及拟新增模块/验收文件，本批不改数据、资料、模型或已采用研究。

## 现状反例

园区第 146 行、机柜第 127 行分别定义 unchecked fetch(...).json；后续顶层 await Promise.all 读取 BOM、公司、价格、指标、模块（园区另有产品）。任一路径 503 返回 JSON 时不检查 HTTP，坏结构在紧随的 records/parts.forEach 抛出；请求失败则顶层初始化拒绝。两者均无超时与错误/重试界面，renderer 初始化尚未发生，控制按钮却已出现。两份场景共享相同启动职责但各自实现。研究摘要的重试只解决档案内的关联，不涵盖本问题。

## 目标职责及权威

新增 scene-data.loadSceneData 只拥有必需定义的请求、集合结构检查、超时、整批取消、错误/重试面板及初始控件禁用/恢复。页面传明确依赖列表，在全部结果有效后才构建领域索引与 renderer；几何、材质和具体覆盖度计算仍属页面。失败只恢复加载，不重新执行已创建 renderer，不复制数据存储。所有数据继续读既有 URL：Git 发布的 BOM/公司/模块/产品、运行权威价格、指标投影。不得根据加载失败改账号/模型/事实，也不以空集合伪装成功。

loading/error/ready 分明；失败或超时取消该批的其他请求。重试产生新批，旧批迟到成功/失败不产生新状态；快速重复点击只启动一次。成功释放提示及计时器，恢复调用者明确交付的控件状态。导航保持可用，错误面板遵守 Attio/folk 与明暗/手机规则。超时默认 12 秒，配置值可供可复现验收；不把 renderer、GLB、HDR、纹理、下钻链的就绪包括在定义加载成功里。

## 消费与退出

唯一公共实现 loadSceneData 的生产消费者为 bom3d 和 rack3d 两页；新 scene_bootstrap 测试为验收消费者；通过 routes 显式暴露资源。两份 get 与裸 Promise.all 启动退出。完整研究接口、档案摘要与可选资产链保留理由在 legacy-removal.csv。无新源码目录。

## 验收与发布

先在隔离本地服务复现 503 中断，再实现。两页通过真实浏览器拦截某个基础请求，验证失败提示、场景控件不可用、导航仍可用；恢复请求后点击重试，要求真实 renderer/档案研究就绪。直接生命周期测试覆盖 HTTP 错误、坏集合结构、超时、批取消、重复点击与旧请求迟到；两皮肤明暗及窄屏检查状态面板。

更新现行规范、政策影响与测试摘要；全站浏览器入口注册独立套件，不把用例继续塞进 part_dossier。严格数据、registry、治理和完整 Python/浏览器/容器 CI 后再合并发布；线上用实际数据及浏览器验证，另记录原文件保护。未完成的可选资源/构图/GPU/历史证据链不因该批通过退出待办。
