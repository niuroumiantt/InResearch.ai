# 3D 构图与视口整改交付

## 已实施

先以 2b8d489 完成 736 基线文件与 48 条引用清点，再实施共享 scene-view。首次清单脚本因中文 Git 路径转义中止，仅两份文件产出；完整清点改用零字节分隔后完成，源码修改在完整证据之后。后续 d90c3e7 先登记“几何断言通过但旧 Fog 让画面空白”反例，再扩展相机/雾化适配。原件、拒绝模型文件、研究事实与运行资料均保留。

两主场景、比较台、部件查看器共用实际画布尺寸与透视算法。主画布从固定导航下沿开始，相机比例与渲染缓冲使用同一实际尺寸；旧 window 全尺寸和 aspect/0.9 zoom 退出。比较台逐帧 setSize 与两预览 rad×2.9 固定距离退出；几何边界按世界坐标，隐藏祖先不参与，旋转使用包围球保证边界，近/远裁剪随尺度设定。园区雾化跟随视距，保留语义与材质。

model-assets.objects 只返回当前成功组的独立数组，不转移资源权；失败保留、替换退出、dispose 清空。主视图初始/显式适配可跟随尺寸，拖动/滚轮或领域动作接管后，迟到资产和 resize 不夺回镜头；适配按钮取消旧飞行。阶段展开不强制搬动用户镜头，使用“适配视图”查看当前完整结构。部件预览重开清除先前 pivot 旋转，按实际 CSS 宽高适配，退出释放 renderer/观察/克隆材质而保留借用几何。原领域镜头配置、阶段与研究语义继续归页面。

公共实现与全部观察到的内部消费者分别见 public-contracts.csv / public-consumers.csv；全文件处置见 file-results.csv；旧实现退出及明确保留见 legacy-removal.csv。新增一个共享源码模块，使用既有 web/components 目录，没有迁目录冒充职责统一。

本机完整 1,013 项 Python 测试通过。真实场景及既有资产/部件相关回归通过；新增构图验收覆盖默认/展开、桌面/360px、导航、实际几何投影、比较登记 GLB 旋转、server/GPU 重开、错误加载→采用版本替换→撤下、当前对象数组隔离、相机用户/领域所有权、空/隐藏/平移几何与尺寸观察退出。已有资产独立进程并发、重试及版本替换来自前批原断言，不被本批改低。本机完整 13 套浏览器回归通过；随后手机查看器、非有限边界、最小按钮尺寸及主体聚焦规则的构图回归分别通过。最终提交云端 CI 和部署结果另记录，不从本机推断。

第一轮浮点精确比较在 3 与 3.0000000000000027 上失败，镜头验收改为 1e-8 容差；不允许实际重定位。第一轮几何通过但画面全雾化，补充最远模型点与雾化远端验收并重新看截图。DPR 1 无界面 Chromium 在不透明 HUD 上方出现镜像残影：DOM 中该处只有 canvas；隐藏/半透明 HUD 可令其消失，样式隔离与 alpha context 无效。同代码有窗口 Chromium 截图无该残影。保留上述诊断与两环境截图，未把更改面板透明度的测试试验写入产品；该环境差异尚未穷尽归因，不能宣称全部 GPU/浏览器渲染验证完成。
