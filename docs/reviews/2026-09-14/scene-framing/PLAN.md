# 3D 可见区域与相机构图：修改前证据与迁移计划

基线 7f9941a061f8e87a3692660f0f1a64245a455cfb，PR 179 上的独立工作树；其最终 CI 修正先整合再实现。本计划先于本批源码修改。全 736 个基线文件逐项登记在 file-plan.csv；48 条观察到的相机/尺寸/公共入口引用见 consumers-before.csv。首次生成遇 Git 中文路径转义而中止，仅产出两个清单文件；本次改为零字节分隔重新完成清点，没有在证据完成前修改源码。

## 现状证据

实际 Chromium、1280×900、DPR 1 截图确认机柜顶部和比较台样例裁切。baseline.json 保存机柜相机、目标、包围盒八顶点投影：最高 y=1.10299 超出 [-1,1]。画布 y=0、900px 高，导航覆盖顶部约 104px。两主页面按整个 window 设置画布并用 aspect/0.9 改 zoom；比较台与部件查看器均用最长边×2.9，未用水平/垂直视场角求距离。查看器按固定 604/380 配置相机，重开时上次 pivot 旋转可能影响居中坐标。

## 目标职责与权威

scene-view 管理实际画布尺寸、基于几何包围球和视场角的适配，以及主场景自动适配与用户操作的所有权。页面提供明确模型集合、固定导航元素、renderer/composer 尺寸回调及现有领域动作；不把研究领域搬入通用层。部件/比较台处理自有预览模型和旋转。模型登记/采用/代次仍归 model-assets；新增只读当前 objects 查询供构图，失败与迟到结果不得改变当前集合。几何来自当前 Object3D 世界变换，尺寸来自 DOM 实际矩形，领域镜头来自显式动作。fit 不改变物理尺寸或授予研究采用权。

公共 fitPerspective / visibleBounds / createViewport / mountSceneView 消费者为两主场景、compare、part-inspector 和新增浏览器测试，按职责分别引用。mountSceneModels 的 objects 新消费者为两场景与回归；旧 ready/reload/dispose 保持。createPartInspector 的 show/tick/hide 由 part-dossier 与两场景消费；如新增释放必须连 pagehide 并验证不释放借用几何。全部消费结果在交付 CSV 逐项登记。

## 实施与退出顺序

先统一实际尺寸和几何 fit，再迁移比较/查看器，随后主场景初始适配、手机与导航布局；显式“适配视图”恢复全景。拖动/缩放或领域镜头接管后，迟到资产和 resize 仅更新画布比例，不夺走用户镜头；适配按钮取消旧相机动画。主题切换保留选择/阶段。主场景取可见研究网格及当前采用模型，背景不扩张包围盒。旧 resize/zoom/固定距离实现删除，不保留双轨。详见 legacy-removal.csv。

## 验收与边界

主场景默认/展开、比较台真实 GLB、部件预览旋转/重开不同模型，桌面与窄屏检查投影边界、相机比例、导航覆盖及有限数值；验证 resize、重复适配、手动接管、迟到模型失败/替换与资源释放。前批资产并发/失败重试/版本替换继续通过，不伪称模型研究正确性。真实截图验看，CI 软件渲染耗时单列。HDR/纹理回退、整体 renderer 生命周期、领域镜头艺术效果、全部浮动面板避让、长期 GPU 性能、Spark/M4 和正式证据采用仍未完成。

统计分源码、测试、文档、数据/配置、审计与二进制，沿用固定分类；旧 pipeline/test 身份全局冻结。完成/验证/未完成分开交付。

## 首次截图后的范围补充：视距与雾化

几何投影断言通过，但截图显示园区近乎空白：适配后的相机视距超过旧 Fog(110,260) 的完全雾化距离。这次不能计视觉通过。先登记再修正：mountSceneView 增加可选 fog 参数，由园区明确提供 scene.fog；共享适配按同一模型边界/相机距离调整雾区，机柜无 fog、比较与查看器不受影响。新增雾化远端大于最远模型点的验收，并重新检查真实截图；不修改模型颜色、尺寸或研究事实。涉及路径均在原计划内。

## 桌面/手机实图后的聚焦范围补充

自动适配把 150×100 的用地底板也作为主物体，模型虽然完整却过小。实测包围球半径 all=90.3375，排除底板的建筑/设备 subjects=43.1034。先登记再修正：园区页面明确把 land 作为可选择的场地背景，保留其网格、研究节点、档案和拾取，只从自动“适配视图”的主体集合排除；机柜继续包含全部研究网格，已采用模型均加入主体。共享算法不认识 land 业务 ID，页面以 framingObjects 明确给出主体。测试验收主体完整及 land 仍可用，重新检查桌面/手机截图。这是聚焦集合的职责规则，不删除数据或缩小渲染的模型。
