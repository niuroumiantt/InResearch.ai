# 模型资产采用与加载：实施前审阅

基线 36c2830，现行 2026.09.14.1。此计划先于应用代码提交；原件、既有 GLB 和生产数据保持原字节。全文件处置见 file-plan.csv，引用全集见 consumers-before.csv。

## 现状证据

两场景各自读取 manifest 并加载所有 page 匹配条目。唯一 GLB 的 note 明确写“用户明确说不采用”，但页面仍请求并展示；hideRack 在单个异步回调中隐藏程序化机柜，整批没有版本、取消、回收或重试。失败只进入控制台或被 catch 吞掉。相同文件再次下载直接覆盖字节、register 删除原条目再写，采用状态/布局无保护，并发会丢登记。

asset-check 有无条件 `if not errors or True`，不核对内容身份、完整 GLB 头/长度和正有限变换。compare 默认读取同一登记但独立实现加载，失败登记变成空结果且空提示马上被清除；?f 可越过登记，模型内部名字拼 HTML。ADD_3D_MODEL 仍写旧 assets 路径、旧静态服务和“30 分钟自动 commit/push”，与现行审核/部署冲突。

## 目标职责与数据权威

* materials.model_assets 是已登记视觉输入的领域契约与作者工作区导入用例；校验文件名、来源/许可、状态、SHA、GLB 和空间变换。不是研究证据采用器。共享 storage.files 的锁/独占原件写入/原子登记作为存储原语，不引入第二套事务。
* web/assets/models/manifest.json 是唯一发布登记，schema_version=1；candidate/adopted/rejected 显式区分。adopted/rejected 必须有决定依据；SHA 绑定被审阅的字节。现有样例依据原 note 标为 rejected，保存 GLB 和说明，不伪造新批准。下载只登记 candidate；同名同字节重试保持既有状态，同名不同字节拒绝，版本用新文件名及新决定。
* asset-download 只适配外部下载/格式，调用同一导入用例。移除许可绕过；解包和 glTF 外链读取限制在下载临时目录，不读工作区外文件。asset-check 是同一契约的诊断入口，CI 运行；asset-compare 仍为本机结构检查，输出不宣称已经可拆或已被采用。
* HTTP /api/model-assets 只读发布登记，验证后输出；page=rack3d/bom3d 仅返回该页 adopted，默认返回全部登记供比较。沿用研究 API 身份边界，无采用写入 API，不调用模型。直接文件 URL 和原二进制仍按原认证边界服务。
* web/components/model-assets.js 统一 GLB 请求、SHA 验证、解析、迟到拒收与独占资源回收；可恢复加载槽拥有请求代次、超时、取消/重试和状态 UI。两页的模型挂载使用同一批次：全部就绪后一次替换，失败保留旧成功组/程序化几何，不能部分 hideRack；被替换或迟到的私有模型释放 geometry/material/texture/image，但不释放主场景资源。比较台也使用同一加载槽和模型读入；仅预览已登记条目，明确采用身份，不因网格多就宣称物理可拆解。

## 全部已观察消费者与退出

model_assets 由 asset-download、asset-check、HTTP 与新单元测试消费；CLI 映射保留旧稳定命令。model-assets.js 由两场景和比较台、新浏览器验收消费，routes 暴露唯一模块。登记的手册/README、现行产品/UI/软件契约、规范注册/验收映射及 CI 同步迁移。CSV 将列每个命中的实际路径、行号与处置，静态引用集合不冒充未知外部客户端盘点。

退出两份 GLB 装载/缩放/隐藏逻辑、compare 独立 GLTFLoader、下载器裸覆盖/register、无条件成功输出、登记即采用和静默空结果。没有源码目录改名；二进制不删除。HDR、面板纹理、renderer、下钻条和相机构图保留并写明原因，属于下一批，不能混称全部资源已收敛。

## 提交边界、失败与验证

导入锁覆盖校验旧登记、同名冲突、独占落盘和登记主提交。已有字节绝不覆盖；原件写入后登记前中断会留下未登记文件，下次相同请求核对字节后恢复。登记提交后 durability 不确定沿 CommitUncertain 明确停止，重试读取权威不重复。并发同文件/不同文件、旧状态重试、新内容冲突、替换失败、损坏/外部 GLB 与符号链接拒绝都用独立进程和真实临时文件验证。

先复现已拒绝模型仍被请求/登记失败吞没。浏览器验证两实际场景默认不请求拒绝条目；注入登记的已采用测试模型验证真实 GLTF 解析与缩放/隐藏、HTTP/SHA/解析失败后重试、批内一项失败不替换、A→B→A 和并发迟到、资源回收及程序化场景保持。比较台验证拒绝身份、失败可见/重试、空集合、文件过滤、非 HTML 渲染名字；Attio/folk、明暗、手机状态不溢出。另跑全 Python、严格数据/registry/治理、全浏览器和 CI；生产只在浏览器注入故障，不修改真实登记或二进制。

交付分别列已实现、本机/CI/生产已验证与未完成。分类统计源码、测试、文档、数据/配置、审计及二进制，不把证据增长混成源码。全站证据采用、Spark/M4 和可选纹理/真实设备帧率仍不由本批完成。

## 实施前补充的路径与存储消费者

真实浏览器基线已复现：rack3d 请求 rejected 样例，compare 的登记 503 后 grid 为空且没有重试。静态服务目前逐个硬编码 GLB URL，新登记文件不自动可达；static.source_path 改由同一登记契约解析 models/ 下的文件，移除唯一 GLB 的重复 routes 条目，未登记仍不可达。storage.files.atomic_write 增加显式 exclusive 选项，原两参数调用语义不变；导入用此选项原子创建完整文件，存在目标即拒绝，避免先写半文件或覆盖。其全部既有调用另登记为兼容保留并回归；产品资料库自身的预备日志流程本批不改。比较页保留不合法 ?f 的纯文本拒绝卡，既有 URL 安全验收继续适用。

## 版本边界补充（先于对应改动）

比较页已复用必需集合加载器，但该加载器只检查集合形状，尚未声明接口版本。为避免新版 API 和旧缓存页面混用，给 source 描述增加可选 schemaVersion，比较页声明 1；版本不符沿同一错误/重试状态，不在调用后裸抛错。现有两场景不声明该字段，原行为保持。对应浏览器反例包含版本不符后恢复，并检查窄屏重试按钮命中层级，不能只断言元素存在。
