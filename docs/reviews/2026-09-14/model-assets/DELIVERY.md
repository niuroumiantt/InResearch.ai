# 视觉资产契约与加载整改交付

## 已完成的实施

先提交 717 文件基线、77 引用和职责/退出计划（207ef7b），随后记录真实浏览器反例（e5468fb）：拒绝样例仍被请求，比较登记 503 后整页空白。共享加载器的版本要求在 0b1fffe 先登记；最终复审发现初版导入事务落在 materials 不符合既有分层，先登记 ef25370，再迁至 workflow，不保留反向兼容导出。

materials.model_assets 只读/校验登记、内容身份与采用状态；workflow.model_assets.import_candidate 持锁协调领域校验、独占发布和登记主提交；下载适配器只下载/转换并调用该用例。asset-check、HTTP 与静态路径使用同一契约。下载仅创建 candidate；同名不同内容拒绝，同名同内容重试保留采用决定与位置。中断留下完整未登记文件，原请求可以恢复；提交后同步不确定明确抛错，不回滚已可见登记。原有 atomic_write 两参数消费者行为保留，新增独占创建由同一原语提供。

manifest 1 明确 candidate/adopted/rejected 与实际 SHA。原样例根据既有明确不采用记录迁为 rejected，GLB 字节保留。`/api/model-assets?page=…` 只返回指定场景 adopted；比较页读取全部身份；静态路径由同一登记解析，未登记文件不可访问。网站没有采用写入 API，也不访问模型推理后端。

两场景退出各自的 GLB 读取/缩放/hideRack 回调，比较台退出独立 GLTFLoader。共同加载器持请求代次、超时、SHA 校验、重试与独占资源释放。整批就绪才替换场景，任一失败保留旧显示组，撤下采用后恢复程序化机柜。比较启动复用必需集合加载器并声明版本 1；HTTP/版本失败可重试，空登记显示明确提示。比较页展示采用身份与署名，模型名字使用文本，网格数量不再作为物理拆解的确定结论。

全部观察到的公共实现/消费结果见 public-contracts.csv 与 public-consumers.csv；全文件结果见 file-results.csv，旧实现处置见 legacy-removal.csv。新建 2 个 Python 责任模块和 1 个共享浏览器模块，使用既有源码目录；没有把源码目录重命名当成整改。

## 已验证的范围

本机完整 1,013 项 Python 测试、12 套浏览器回归通过。后续版本字段补充后，场景启动/模型资产/URL 文本三套相关浏览器通过；导入职责迁移后 12 项资产用例重新通过。严格数据和 registry 校验通过；治理须在最终清单刷新后再次通过。云端 CI 与生产上线另记录实际提交和日志，不能由本机结果推断。

资产用例使用真实临时文件和 6 个独立进程：并发同名/异名无丢登记，已采用/拒绝状态在重试中保留，同名新字节不覆盖，中断后恢复一次登记，提交不确定可见，独占发布失败不留下半文件。HTTP 实测采用筛选、非法参数、损坏登记 503、未登录 401、intern 403；静态路径由登记决定。下载 CLI 用受控外部响应验证调用同一用例；未进行新的真实外部下载。

浏览器通过两实际场景默认不加载拒绝样例、真实 GLTF 解析与高度、整批失败保留旧组、撤下恢复、比较身份/空集合/版本拒绝、SHA/无效 GLB/坏内嵌贴图失败后重试。生命周期验证超时、重复重试、A→B→A、取消后迟到释放，以及同模型共享 geometry/material/texture/ImageBitmap 只释放一次。最初资源测试的 PNG 样本无效，不能计通过；修正样本，并发现/处理 Three.js 吞掉内嵌贴图错误的情况，新增坏贴图反例后通过。两皮肤、明暗和 360/1280 宽度还检查重试按钮实际命中层级。终审补齐重试按钮的主题配色和最小 36px 高度，并增加至少 4.5:1 的文字对比验收，退出浏览器默认按钮外观。
