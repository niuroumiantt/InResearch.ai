# 对象总览、研究主题与厂商导航

> 2026-09-06 · 提案，待讨论采用。依据用户的 SSD 页面反馈；本记录不表示页面、对象或问题 schema 已切换。当前执行规则仍见 [CURRENT](../../../framework/CURRENT.md)。

## 问题与判断

现有 assets/research-graph.js 的六个节点标签是记录类型：关系、产品目录、问题、材料/证据、陈述/答案、任务。它们并非行业研究角度，也不是严格先后步骤。当前 SSD 节点的说明只有“从现有storage节点拆分”，不能承担产品介绍。正式框架已有八组节点内容契约，但把研究主题与证据/任务混在一起，未形成可阅读的对象综述。

用户明确要求补产品及行业整体介绍、顶部厂商 logo 点击定位，以及固定研究角度。这些需求已记录；以下九主题及具体页面组织是本次建议，尚未替代现行契约。

## 三个维度分别建模

1. P/F/V/D/R：从什么入口找到对象；保持当前五视角及共享对象 ID。
2. 研究主题：围绕对象研究什么；问题有一个主主题，允许相关主题引用。
3. 研究记录：问题、材料、证据、回答与任务；各主题共用同一底座。

总览是已有知识的综合交付视图，不新建独立事实库。正文段落、图表和判断须引用有版本的证据/答案；缺失、争议、背景草稿明确标注。材料存在不自动产生总览结论，材料较新不自动覆盖历史证据。

## 建议的九个固定主主题

| ID | 主题 | 主问题与范围 |
|---|---|---|
| T01 | 定义与边界 | 对象是什么，包含/排除什么，术语与分类；研究的产品层级 |
| T02 | 结构与技术 | 构成、原理、接口、固件、技术路线及演进机制 |
| T03 | 应用与需求 | 谁在什么业务中使用、负载如何产生需求、采购与采用条件 |
| T04 | 性能与选型 | 明确工况下如何测量、比较、兼容和替代；测试结果与选择条件 |
| T05 | 市场规模与周期 | 口径统一的市场数量、收入规模、供需缺口、库存与周期 |
| T06 | 生产与供应链 | 材料/工艺、制造、产能、良率、交付和依赖；供给如何形成 |
| T07 | 厂商与竞争 | 主体角色、产品组合、份额、竞争位置、合作及壁垒 |
| T08 | 价格、成本与商业 | 单位报价、合同、成本结构、利润与使用方 TCO；价值如何分配 |
| T09 | 部署、运维与约束 | 安装运行、失效与寿命、维护退役、安全合规、资源环境要求 |

未来趋势、风险、地域和时间不另开一个无限包容的主题：每个主题分别表达现状、历史、预测、假设、反证与风险，并带地域/配置/时期限定。跨主题因果通过关系连接。

MECE 在约定范围内执行，不能宣称九类天然永久穷尽：每个原子问题一个主主题及责任人；复合问题拆分；相关主题引用不复制事实。市场总收入主归 T05、单位 ASP 主归 T08、公司份额主归 T07、产能/良率主归 T06；从这些量推导的预测记录依赖。测试条件下的耐久度归 T04，实际运维失效归 T09。新增问题无法合理归属时进待分类队列，定期审查框架版本，不静默丢弃或无限增加一级栏目。不适用要记录理由，不能按相同模板给所有节点编造内容。

## 页面建议

默认进入“产品与行业总览”（非产品节点显示“对象总览”），现有链接 tab=relations/products 等继续有效。

总览上方提供边界、简明介绍、关键结论与最近核验日期；下方以九主题目录展开，展示已知内容、关键图表、相关报告、争议与缺口。行业报告只是一类材料；可从总览的“行业报告与数据”进入，同时在材料库保持唯一身份。

六类现有记录入口保留，作为深入研究与出处追溯。研究问题也可按九主题分组。总览、问题和材料不可各自维护互相冲突的一份主题树；采用后须建立统一主题声明和问题映射，不能只在前端硬编码标题。

厂商栏顶部放“标识 + 名称 + 当前匹配产品线数量”的可搜索索引，点击滚动到对应厂商分组并移动键盘焦点；长目录可展开，保留现有筛选。按当前节点相关产品生成索引，不声称收齐全球厂商。真实 logo 登记来源并本地使用；缺失时用名称占位，不生成假 logo。厂商组拆成独立主体后才展示各品牌，禁止同一集合记录使用单一公司标识。厂商可跨供应链角色，角色是有时间范围的关联，不能按 logo 给公司唯一分类。继续使用 Attio/folk 视觉规范。

## SSD 与 NAND 边界及附件

现有 part:ssd 名为“企业级SSD/NAND”，aliases 同时含 SSD 与 NAND。应提出有旧新 ID 映射的拆分：SSD 整盘类别、NAND 存储器、SSD 控制器分别建立身份，用组成/供应/用途关系关联。消费级与企业级、闪存类型、协议、外形分别按各自维度分类，不能混成同一层互斥兄弟项。拆分前核对 12 条关联产品线、问题、材料及 3D/BOM 旧入口，保留 legacy 映射；本提案不直接改名或转移已有证据。

依据 SNIA 的 SSD 定义，SSD 通常包含 NAND 和控制器，二者不能当成同一市场对象：[What is an SSD?](https://www.snia.org/education/what-is-ssd)。

用户提供 `2023_Yole 202302 NAND Market Monitor Q1 2023 PRELIMINARY.xlsx`。本次发现该文件为 iCloud dataless 占位，读取未完成；未检查工作表或数值。只能根据文件名登记为待核对的历史 NAND 市场资料，不能宣称报告包含某一指标、已完成深读或代表当前企业级 SSD 市场。取得完整文件后按文件哈希、工作表、单元格范围、单位、统计期间、发布时点、预测/实际、PRELIMINARY 修订状态定位；NAND 总市场与企业级 SSD 子市场不得直接等同。原文件不进入源码仓库。
