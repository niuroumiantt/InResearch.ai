# L2 深读职责与写入整改交付

本轮完成 L2 的职责拆分与已复现写入缺陷修复，尚未完成整个项目的架构整改。规范版本为 2026.09.13.6；语义验收覆盖仍为 partial。

## 修改前证据与集成范围

先以 26f617b 提交 PLAN、反例、591 个基线文件的处置表、38 个原公共函数和消费者引用，再修改实现。冻结基线为 465f8de。实施期间主分支合入 PR #167 断言者契约及研究数据，另以 20814b8 为集成比较基线；该变化在 PLAN 的集成补充中登记，不能把上游数据增长混成本轮整改。

原反例可见 baseline.json：受限材料绕过队列直接录入；同一请求重复完成回执；已填缺口被旧 skip 重开；缓存映射用 JSON 子串猜错 SHA；歧义前缀打包选中第一份。原测试通过并未发现这些问题。本轮另外对齐现行 M4 任务卡的 ≥7 / 用户点名规则、6000 字预览、人工完成声明与正式评分的区别。

## 旧实现退出和保留

已退出：workflow 中的 argparse/print/sys.exit/main 和 cmd_*；fact_write 装饰器隐式事务；L2 对领域、文本算法和交付函数的聚合转出口；固定 SHA 前缀包文件覆盖；JSON 子串/文件名猜来源；重复写完成记录；skip 重开已填缺口；从当前服务器版本临时取值来代表旧客户端基线的归属/限制修改。

旧 tests/unit/test_m4_l2.py 已删除。冻结基线 402 个测试加上游新增 11 个，全部迁入 test_fact_contract、test_deep_read、test_text_similarity；[test-results.csv](test-results.csv) 逐条核对 413 个测试身份。新增 29 个事务/故障/并发用例。重复销账从“拒绝”改为“重放成功”，来源命令不再提示自动降低 PROVENANCE_DEBT；直接 CLI 函数测试改检 ValueError，真正 main 保留结构化错误退出；包测试改读返回的独立路径。上游材料回填测试的固定批次名单保留，未为了绿色测试放宽事实规则。

仍保留及原因：

- facts、metrics、原件、来源、旧移动日志和旧包：研究证据与身份历史，不是待删代码；本轮未迁移实际资料。
- l2_read.jsonl、l2_text_md5.jsonl、metric_gaps.jsonl：沿用已使用的存储格式和位置；twin_of 历史行单独计数，不能让未读材料出队。
- 底层 files/JsonlStore：复用现有跨线程/进程锁、原子替换和尾行恢复，没有另建一套存储工具。
- DeepRead 与 reader：本轮整理 L2 用例，没有将两个运行体系强行合并；跨体系的一套当前全文阅读结果仍待设计和迁移。
- 现行规范文件名保持稳定：CURRENT 登记唯一入口，审计快照另存；改名不等于替换生效规则。

## 已验证及其范围

Python 3.9 全量 939 项通过（集成基线 910 + 新增 29），不是仅运行迁移后的测试；严格数据校验 0 warnings，118 个对象和 449 个问题引用有效。规范验收映射为 13 个 scope，已逐项迁移并复审本次改变的映射及断言，不由 governance --refresh 自动批准。

实际业务链：隔离 431 字合成原件 → L1 score 7 队列 → 完整包 → 真实 Claude CLI → facts 录入 → 原请求重试 → 再开独立包。每个 CLI 步骤运行在新 OS 子进程，使用显式隔离路径注入；manage.py 注册/help 另测。模型执行器报告 claude-code / claude-opus-5；两条事实、一个完成回执，原件 SHA 不变。Codex 逐项对照完整原文和生成结果，6 处逐字引用匹配；1.8 kW 为服务器派生小计，2.4 kW 为机柜 IT 上界，未知断言者没有编造，未推算设施容量、能耗、电费或余量。完整脱敏证据见 [real-flow.json](real-flow.json)。一份合成材料不能代表全语料阅读质量。

故障验证涵盖事实提交前失败、事实已提交而回执失败、原子替换后持久性未确认、缺口主提交后回执失败、未知批量销账、发布中断、损坏台账和失效来源计划；均核对权威内容后重试。并发验证使用独立进程竞争事实、缺口和 L1 基线，另验并发包不覆盖。版本验证包括旧 L1 修改拒绝、事实或解析路径改变使旧来源计划失效，以及新增争议反向链接后旧事实请求仍可重放。新实绩修订与来源争议在同批录入中也必须满足上游契约。

PR CI 和生产发布结果在交付提交时尚待执行，最终结果记录在对应 PR 与发布验证报告中；本文件不以计划冒充已上线。
