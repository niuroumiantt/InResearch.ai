# 3D 输入与动画职责整改：修改前证据

基线 f448b31（新闻投影候选；生产数据边界已验证于 73e0c4c）。新增方案限于场景输入、视觉提示和动画所有权，补充 05；不替换研究标准、事实、几何或资产许可。

## 已观察的反例
- 两页面各有完整 `setHover/pick/pointermove/click`。setHover 恢复强度却不恢复原本黑色的 emissive；直接改共享材质会影响同材质其他网格。
- 拾取以整个窗口计算，window pointermove 穿过 HUD/档案；click 只排除部分 CSS 选择器，拖动与点选无共同判定。
- 播放按钮每次新建 RAF，园区 animSlider 另开 RAF；手动滑杆/阶段/连续领域切换不能统一取消旧写入。
- 园区 setDim 直接改共享材质，用材质 userData 存“原值”；独立网格的领域归属会互相干扰。

## 目标职责与数据权威
- `scene-picking.js`：只接受主 canvas 输入；canvas 局部坐标拾取显式网格，忽略不可见祖先；一次手势区分拖动/点击；单一临时高亮覆盖网格，不写原材质/研究记录；clear/dispose 清理。
- `scene-motion.js`：每个连续状态只有一个可取消时间线；新目标取代旧目标；即使旧 RAF 已进入队列也不得写新状态。页面负责阶段表/插值/相机目标；reduced-motion 直接到目标。
- 页面：BOM ID、几何、阶段与领域配置及档案装配。园区淡化只创建该网格临时材质，退出恢复原引用并释放克隆；热图与领域互斥保留。
- `installStageControl`：保留公共选择控件，通过 input 通知唯一滑杆控制者；主 canvas 不接收档案画布输入。
- 数据继续来自现行 BOM/研究注册表与既有价格投影；本批无新事实库、无部署挂载更改。

全量文件计划见 file-plan.csv（全部基线文件逐项留存/修改/新增），全部已观察入口引用见 consumers-before.csv。新增公共实现消费者预计为两场景及浏览器验收；结果清单修改后逐项登记，外部未登记调用不冒充已证明。

## 验收设计
真实两场景/两个皮肤/档案拖动与关闭；快速重复播放→阶段/滑杆接管；领域 A→B→全景；reduced-motion。用真实 Three 网格共享材质验证高亮/淡化无污染、overlay 不拾取、不可见祖先不拾取、拖动不触发档案、移出清理。通过可控帧时钟故意重放被取消旧回调，检查新目标不被覆盖、停止后不再写。页面失败日志零错误；失败恢复可重开、正常输入之后重新播放。既有全站浏览器/严格数据/治理回归继续运行。发布另验 HTTPS 源字节和当前规范，不以测试绿色代替全部 3D 架构完成。
