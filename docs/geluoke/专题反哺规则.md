# 专题研究反哺规则

版本：2.0｜更新日期：2026 年 9 月 28 日｜取代 1.1（2026-09-27，反哺 `cost.html`）。

## 一句话

专题文章不是执行指令，也不是第二份事实：文章取得的新数据只以**带 `node` 与 `variable_class` 的登记**进入登记表，页面与成果从登记表生成。

## 规则

1. **落点只有登记表。** 价格类进 `data/prices.json`（`series_id + as_of` 唯一，带 `grade`、`source_url`，`estimate` 附 `assumptions`）；数字事实进 `data/facts.json`（带指标、口径、时点）；两列 `node`、`variable_class` 由 `python3 manage.py nodes --refresh` 从骨架派生，不手写。
2. **序列 ID 按骨架命名。** 用部件 / 权利 / 根 + 变量含义命名（如 `transformer-lead-time`、`power-price-state-industrial`），不再用模块前缀（M01–M15 只是兼容属性）。
3. **模型输入的改动走评审。** 文章校准了统一经济模型的哪个输入，就改 `data/datacenter_model.json` 的假设与 `evidence`（状态 sourced / assumed / input 与来源），由 `test_model.py` 的校准锚守住；不新建计算器、不改页面结构。
4. **交付回目标表。** 文章补上的数据对应目标表哪一行，就在价格记录里写 `target_id`（进入 delivered 的 Git 内载体），或在采集页按行登记交付。
5. **文章留在 `docs/research/`。** 带日期与"不是当期报价或投资建议"横幅；不进 `framework/`，不作当前执行指令；成果页只从登记表生成，专题只在末章目录里出现。
