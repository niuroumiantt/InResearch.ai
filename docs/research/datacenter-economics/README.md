# 数据中心经济模型（四本账）

> RESEARCH MODEL · 2026-09-27 · 持续维护的研究能力，不是当期报价、预测或投资建议。

`economics.html` 用一个项目定义回答"一座数据中心的钱从哪来、到哪去"：同一个 IT 容量、芯片代际和设施方式，分别站在四个主体的账上算投入、成本、回报与利润分配。它替代"为某篇文章算某个角度"的做法：文章提供校准点与视角，模型是可持续更新的公共资产。

## 权威边界

- 网页口径与全部假设：`data/datacenter_economics_model.json`（schema 1）
- 前端引擎：`web/components/datacenter-economics.js`（`window.InresearchEconomics.compute`）
- 参考实现与校准断言：`model.py` → `results.json`
- 基准数字：`data/prices.json`，页面按 `benchmark_series` 取最新时点
- 浏览器测试：`tests/datacenter_economics.cjs`

## 四本账

| 账本 | 主体 | 核心输出 | 计算 |
|---|---|---|---|
| L0 芯片层 | 加速器厂商 | 项目资本开支中流向厂商的毛利（年化） | IT 资本开支 × 加速器占比 × 毛利率 ÷ IT 折旧年限 |
| L1 壳层 | 土地、电力、建筑的出租方 | 成本收益率、杠杆现金回报（税前/税后）、DSCR、无杠杆/杠杆/税后杠杆 IRR、含续约期权 IRR、合同总额（基础期/含期权） | NOI = 租金 × NOI 利润率；债务按租期等额还本付息；现金税 = (NOI − 设施折旧 − 利息) × 税率；续约期 NOI 按行权概率加权 |
| L2 算力层 | 算力运营方（超大规模云、新兴云） | 收入、EBITDA、NOPAT、ROIC、盈亏平衡价、回收期、无杠杆 IRR（含租金年变动路径）、GPU 抵押债务下的税后杠杆 IRR 与权益倍数 | 收入 = GPU 数 × 8,760 × 付费利用率 × 租金；成本 = 电费 + 其他运营 + 壳租/托管费 + 折旧；ROIC = NOPAT ÷ 投入资本；租金按年变动进入 IRR 路径；债务按 IT 年限等额还本付息、利息抵税 |
| L3 模型层 | 模型/API 公司 | token 收入、NOPAT 利润率、ROIC（自有算力时） | token = 收费 GPU 小时 × 3,600 × 吞吐；成本 = 自有算力运营 + 折旧，或租用租金 |

设施方式决定账本之间的关系：自建自持时算力方承担非 IT 资本开支；租带电壳时算力方付租金、壳层收 NOI；托管时算力方按 kW 付费。算力来源决定模型层与算力层是否合并。

## 骨架：TCO 因子树（`framework/tco_factors.json`）

模型的骨架不是某个公式的数字，而是一棵因子树：收入侧（GPU 数、密度、利用率、单价）与成本侧（电费、其他运营、设施费、折旧与资本开支、税），外加跨账本的资本与融资。每个因子登记：汇总的爆炸图部件（`bom.json`）、读取的价格库序列、对应的研究问题、进入模型的输入键、定向抓取目标（产品 / 新闻 / 数据 / 报告，含来源与频率）。单元测试 `tests/unit/test_tco_factors.py` 保证引用都存在、每个模型输入都归属某个因子、每个叶子因子都有抓取目标或序列。页面底部展示这棵树。

爆炸图回答"资本开支由什么组成"，因子树在它之上加运营、财务、商业、收入四个维度；部件价格或规格变动时，沿因子树进入模型的对应输入。

## 与 cost.html 的关系

`cost.html`（2026-09-14）是单账本的全成本计算器：资源、设施、设备、任务、资本回收五段成本与每有效设备小时成本，加一个收益参照。本模型把它扩成四本账，共用价格库基准。两页并存：成本计算器保留 2026-09-14 研究基准与 Excel 对账，经济模型承担多主体分析。

## 更新规则

- 新的校准点（研报、公告、财报）先进研究档案与价格库，再作为预设或断言加入；预设的 `note` 写明来源与作者拆分。
- 新代际先加进 `generations`，标注哪些字段来自来源、哪些是作者估算。
- 引擎改动必须同步 `model.py`，断言通过后再改前端；浏览器测试核对校准值。
- 页面上不保存基准数字，基准全部来自价格库序列的最新时点。

## 已知边界

- 折旧按直线法；算力层 ROIC 按 NOPAT 口径，IRR 与壳层现金流含逐期现金税与利息抵税，不做加速折旧。
- 壳层续约期权按行权概率加权进 IRR，不做期权定价；残值按投资比例假设。
- 算力层租金路径只做固定年变动，不做利用率爬坡与再定价合同。
- 模型层的吞吐与 token 价格是把研报每 GW 收入反推出来的组合，不是任何模型的实测。
- 芯片层只显示毛利份额，不是厂商财务预测。
- 中国情景的汇率、杠杆与利率为作者假设。
