# 数据中心全成本研究档案

> RESEARCH ARTIFACT · 2026-09-14 · 不是当前行业报价或投资建议。

本目录保存“数据中心成本重新估值”专题的研究正文、来源核验、材料审阅、可复算模型与 Excel 工作簿。它从 `inews.today` 的公众号交付目录迁入 `inresearch.ai`，因为成本模型属于持续研究能力；公众号 HTML、X 发布包和二维码等渠道交付物仍留在原发布项目。

## 权威边界

- 网页计算器的当前输入口径：`data/datacenter_cost_model.json`
- 计算公式实现：`web/components/datacenter-cost.js`
- 可下载、可审阅的完整工作簿：`datacenter-cost-model.xlsx`
- 研究叙事与证据线索：`article.md`、`sources.md` 和各材料审阅文件
- 参数是研究假设；第三方报告与用户本机原件没有复制进 Git。

网页与 Excel 的基准结果必须一致：年化总成本约 11.678 亿美元，每有效设备小时约 4.10 美元，全年设施用电约 766.5 GWh，现场耗水约 49.06 万立方米。

2026-09-27 补充：盈利专题在同一公式上增加收益参照与情景预设，本基准与 Excel 不变；见 `docs/research/2026-09-27/datacenter-profit/`。
