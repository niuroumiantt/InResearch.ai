# Spark 持续资料阅读 - 当前目标与接口

> 2026-09-06 用户采用生效。旧 datacenter-reader 有限批次计划 **SUPERSEDED / 已被替代**，不可作为启动指令。正式标准：[阅读标准 v3](../../framework/04_reading_scoring_standard.md)、[执行协议](RUN_TO_COMPLETION.md)、[架构 v2](../reviews/2026-09-06/RESEARCH_ARCHITECTURE_V2.md)。历史规模、主机和完成数字只描述当时账本，不代表当前磁盘或服务状态。

## 当前目标

Spark 长期接收 raw-materials，27B 粗读后对每篇独立文章深读，原文证据关联对象、接口、问题和数字/非数字陈述。接收、阅读、质量、分类、核验和采用分别登记；低分不淘汰，新料和旧积压均持续推进。

研究既由框架提出缺口找资料，也由新材料产生证据、反证和新问题。15 模块保留兼容导航，分类可细化到对象/关系，不新建重复公司、资产或原件。

## 当前职责与存储契约

- Spark：inresearch 原件、完整阅读、永久资料台账与候选的常驻处理；由进程管理器守护，阶段小任务有检查点、有限重试和异常出口。
- infra：模型网关与通用推理能力；不擅自迁移 mini/OA 其他任务，不能把临时队列 TTL 当资料生命周期。
- 研究主项目：正式定义、口径、C3 采用、可追溯 Finding、问题与交付；使用原页证据，不只读 CSV 摘要。
- 源码：`~/code/inresearch.ai/`；Spark 数据：`/home/spark/.local/share/inresearch.ai/`，运行状态：`/home/spark/.local/state/inresearch.ai/`。m5 临时下载和 PDF 等产物位于 `~/.local/share/inresearch.ai/`。原件/数据库/阅读产物不进 Git。

常驻是已批准的运行模式，是否实际启动以部署记录和进程/台账健康检查为准。本计划不把文档存在当作服务在跑；实际命令以当前运行手册和实现提供的 CLI 为准，不执行旧 `start.sh` 或历史独立项目提示词。

## 成功标准

每篇有正文/附录/图表覆盖与执行依据、全文报告及候选去向；每个采用值/陈述能回原文；原件和哈希保持；断点恢复不重复采用，同名异文不覆盖；低优先级文章真实推进；C3 待审不阻断阅读。吞吐按格式/长度/语言分层实测，按批次与截止日展示积压年龄和失败，不预设十天或三十天必读完。

C3、现行中外/数量口径、官方未披露容量不推算、原件只留不删保持。详见正式阅读标准。
