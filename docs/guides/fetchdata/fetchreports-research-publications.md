# C 员工任务书：fetchreports 研究、白皮书与标准

先读 [共同交付规范](delivery-contract.md) 和 [开发与验收](implementation-and-acceptance.md)。你收研究结论及其方法，不代替官方产品规格抓取或公司披露队。

## 目的与对象

把论文、研究机构、行业调查和标准中的可定位信息变成可复核候选：原生测量、估算、区间、适用范围和方法一起保留。研究报告本身有作者/机构/版本身份；样本总体或某基准测试不是唯一园区，不能硬塞到园区表。

## 首批来源和范围

1. **Epoch AI**：[数据中心公开数据入口](https://epoch.ai/data/ai-data-centers?tab=power)。取得实际下载数据及其说明、所用来源链接；标明它们的估算性质/时间/地点粒度。它的集群/园区身份需要复核，不能同城就合并、把设施功率变为 IT 功率。
2. **LBNL**：[美国数据中心能源报告原发布页](https://bies.lbl.gov/publications/2024-lbnl-data-center-energy-usage-report)。从发布页取得可公开下载的报告，保留全国估计/情景、统计区间、方法和图表。不能把国家总量分给某公司或站点。
3. **arXiv**：[API 说明](https://info.arxiv.org/help/api/index.html)。选 3 份与数据中心冷却、能耗或 AI 集群测量直接相关的公开论文，保存查询条件、作者、ID 和版本，人工确认相关性再批量。保留 v1/v2，遵循当前源限速与授权。

首批合计 3 家来源、5 份资料、至少 10 条可定位候选；不足时写出未取得或无直接信息的原因。不得绕过付费墙、把受限标准全文转公开；可以只交合法取得的元数据及受限标识。

## 要抓的信息

| 指标名 | 同时保留 |
|---|---|
| study.pue / study.wue | 定义、样本量、地区/年份、均值/中位数/范围，水分母和取水/耗水区别 |
| study.energy / study.water | 量纲、期间、研究总体、方法、误差/情景；未来预测单列 |
| study.construction_cost | 地区、币种、价格年、设施/IT/土建范围、$/MW 的分母 |
| study.benchmark | 型号、软件版本、精度、批量、硬件规模、利用率、测试方法；作者主张和实测结果分开 |
| study.capacity / study.timeline | 具体对象、地点粒度、计划/投运、估算区间、原始引用 |
| study.method / standard.requirement | 方程/定义/要求的版本、适用条件及段落；不是给园区背书 |

## 方法

先保存原件和目录，再定位相关页/表/段，读关键上下文及脚注，逐条提取；不等整篇完整阅读。某条结论需跨页方法时读够其上下文，缺上下文暂留候选。原文计算出的估算标 estimated/calculated，未来情景标 forecast；不因研究机构知名就改 measured。

引用了其它文献但未取得一手来源时，明确 `secondary_reference`，只交本报告真实陈述，不声称已验证被引原件。对唯一园区有证据的条目可给 matched 建议，其余 study/product/company 对象或 unresolved 线索保留。研究目标关联可后补。

每周查源更新；arXiv 按实际源日历检查新版本；每月重查在用版本及勘误。报告更新保留版本和旧引用位置，不能用新 PDF 页码回写旧证据。

## 存量优先与本队验收

优先在 Spark 已有报告里取所需段落、表格，不重复下载和全文模型阅读。交文件 SHA、物理页、原文短引及上下文；OCR 记录派生版本，表格数字人工抽核。

交 5 份资料版本表和 10 条原文核对；回归包含原生区间不取中点、预测不作现状、总体不作站点、二手引用不冒充一手、报告修订不覆盖旧版。论文多并不等于有效信息多，不能只交摘要。

这些是公开来源起点，入口于 2026-10-11 核查；取数时仍须核对实际报告/数据版本及使用条件。
