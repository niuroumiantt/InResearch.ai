# TA-13 整柜结构示意的范围

正式静态图和独立整柜交互解释同一示例分区：底部两电源架各六模块，中部八计算托盘每台八载盘，顶部两交换机。数量、位置比例和前脸细节是本图选择，不是通用标配、原厂数字孪生、ORV3 规格或实际机房。原已验 TA-11 独立服务器保持自己的内部布局；本图闭合机箱不证明其所有托盘内部都是同一型号。

前门与左侧柜壳是原位虚拟剖口，右侧壳、顶板和后板保留。三维用独立外框柱、前后安装立柱、左右内外导轨、前后支撑端、固定耳、支脚和真实开孔的前脸表达安装关系。静态图不能证明深部导轨、公差、载荷、接地、端口协议、维修操作或热插拔；U 高度、真实尺寸与额定功率均未知。

静态图左侧服务槽可见铜色长条和灰色竖管。最初制作提示词以母排/歧管形态指导绘画，但没有真实接线、流体回路或原厂依据，因此最终图注仅把它们当作可选未接附件。交互中的铜色长条和管道均映射 `rack-frame` 整柜上下文，不取得 `power-shelf` 整流电源架或 `manifold` 完整配液通路的事实；不连接 TA-11 风冷服务器。两个独立电源架的类别仍为 `power-shelf`。

默认及无部件的 `x=0` 入口接入新整柜；其滑杆明确为“整柜分区观察”，只改变分组可见性，设备不移位。旧 `x=35` 分层、`x=90` 芯片近景以及其它部件深链保留原范围，不能因整柜完成就把 TA-14/15 计为完成。新的整柜不加载旧原厂面板贴图，也不接受旧可选 GLB 隐藏/替换；旧面板来源和旧模型采用流程留在明确的旧场景回归。

程序几何与静态母图逐项对照分区、数量、朝向、虚拟剖口和安装关系；两者的端口密度、柜顶孔、侧槽支撑/线缆导向细节为独立通用表达，未声称像素或原厂细部完全相同。完整档案通过既有 `rack-frame` 研究锚点明确显示“整柜上下文”，聚合全部实际几何；子部件点选只预览该单个示例实例，并保留既有类别 ID。
