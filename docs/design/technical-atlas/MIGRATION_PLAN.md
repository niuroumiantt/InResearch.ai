## 每项完成凭据

| 项目 | 必须记录 |
|---|---|
| 内容 | 对象ID、通用/具体型号、结构/数量/接口来源、未知项、原件/许可 |
| 视觉 | 暖白、细线、真实克制色、轻阴影、分层/定位、留白、独立标注逐项通过 |
| 文件 | 新旧版本关联、style_id、参考图SHA、真实尺寸、制作方式、输出SHA |
| 页面 | 正确入口、点击/拆解/放大/旋转/档案、深链、手机、深色控件、导出 |
| 结论 | 实际截图/测试/审阅结论；accepted与published分别记录，不以文件存在代替验收 |

未建模部件保留“未建模”。领域和部件预览的子清单在领取该项时按当时实际对象扩展，登记图号/部件ID；不能以一个总览验收替代全部部件。未来新增任何技术插图先登记现行style_id及对应参考，加入本队列/交付记录，再进入制作。统计图、原厂证据图保留它们的事实表达，不为了样式捏造信息。
