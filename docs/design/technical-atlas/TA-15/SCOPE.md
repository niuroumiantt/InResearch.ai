# TA-15：芯片封装独立近景

本项对应原35项第15项、`rack3d.html?x=90`。一个通用硅中介层封装独立成为主对象，包含一个逻辑裸片、四组HBM、一个硅中介层、一个封装基板及底部焊球。不增加骨架对象或正式研究事实；GPU/HBM研究链接仍是类别入口，不证明这张示例的厂商、型号、工艺、容量、带宽或功率。

## 参考与技术身份

R3原件 `docs/design/technical-atlas/references/03-ssd.png`（SHA34823652…c7079）用于细线、材质层次、竖向分层及局部放大的画法；不是将SSD技术结构移植到芯片。TA05已验母图 `web/assets/technical-atlas/hbm-package-v1.png`（SHA263a421a…c1f6e）用于一个逻辑/四HBM的通用封装身份。两个实际原件均已查看并传入内置imagegen；两版AI候选的五个顶部接触面投影未能保持同一装配轴，均拒绝，原件和提示词留存。最终依据framework10允许的受控SVG/3D方法独立制作，不将AI候选或交互导出称为母图。

本轮重新读取TSMC官方CoWoS页面和Micron官方HBM说明。它们只支持逻辑/HBM并排、硅中介层和堆栈内TSV这类关系；CoWoS-S、R、L有不同实现，本图不能代表全部方案。八层DRAM、六个剖口铜柱、焊点/布线数量、厚度、材料色及比例均是图示选择，未采用任何型号或额定数值。

## 同一几何与接触对应

`chip-package-assembly.js`由同一factory提供静态母图和独立3D；固定基板的上表面与108个示意C4下缘、C4上缘与中介层底面均在结合位置相接。逻辑裸片和四HBM底部200个示意微凸点分别与中介层对应pad保持相同x/z和接触高度。顶部五个实例只有共同竖轴平移，没有转动、横向挪位或补出额外器件。中介层先整体上移、顶部再分层，基板及其280示意焊球保持连接。平移仅解释层次，不是制造、拆修、热插拔或可拆卸结构。

HBM2虚拟剖口暴露硅体内部六根TSV，铜柱不高于顶部DRAM层；另三组保持完整。中央裸片保留光滑硅面和边界，未补造逻辑floorplan。中介层示意线路不构成已核实routing或真实pitch。未画焊膏/underfill/基底完整细节，不能作为工艺图。

独立公开只读 `chip-atlas.html` 提供完整标注、轻量预览、真实PNG/SVG下载与x90往返。GPU/HBM类别默认母图仍为TA04/TA05，只有显式chip上下文显示TA15。x90默认独立近景，`view=chip&explode=0`可直达结合阶段；非GPU/HBM显式部件深链保留原场景，`view=legacy&x=90`保留历史阶段。
