# TA-12 原生正交母图制作配方

身份：制作记录，非新增运行指令。用户要求继续35项逐张重制；本张使用现行正交平面配方与经核对的TA11程序几何，以独立原生渲染形成母图。

- `renderNativeServerPlan`：真实 `OrthographicCamera`，竖直向下，前 +z 在图下，后 -z 在图上；1536×1024、pixelRatio=1，不插值、不挪动部件。
- 与TA11共用 `buildServerAssembly`：双CPU、八DIMM、双加速卡、四风扇、四列上下两层共八载盘、双PSU及一个NIC均为示例数量；顶盖仅虚拟省略。
- 原生平面材质映射为白/浅灰填充、现有深灰轮廓；来源几何、端口朝向与安装位置保持。没有使用AI图片生成或修改，不把截图放大充当母图。
- 先实际查看R2原件及TA11母图，按前后分区与装配关系逐项比较；R2的透视、精确计数与厂商结构不作产品事实。GPU程序示例顶罩与TA11剖视露鳍片差异直接记在标签/说明。
- 严格俯视只见上层四盘、风扇框架与I/O背壳；下层四盘、竖直叶轮与外部插口遮挡，不为全部可见而平铺/移动/旋转部件。
- 独立可编辑SVG15文字/12引线；没有额外构件或装配箭头。存储背板定位在载盘后方，不误指风扇接口板。
- 非CAD、非真实尺寸、无U/毫米/功率/容量/气流/性能/针脚/兼容性与维护条件。实际网址/来源/PNG和几何SHA在preparation-v1.json；正式公网发布另验。
