# TA-14 分层装配对应示意的范围

本图沿用 TA-13 同一通用几何：顶部两交换机、中部八计算托盘各八载盘、底部两电源架各六模块。每类仅平移一个代表实例：`rack/switch-1`、`rack/compute-4`、`rack/power-shelf-1`；各自原位空出，其他实例保持安装位置，未复制出第二台同身份设备。数量、比例、端口与材料均为图示选择，内部配置、型号、U高度、尺寸、功率、电压、协议及承载未知。

TA-13 省略的前门和左侧板在本图以虚拟壳件补画，顶盖使用原有同一几何；门沿前轴、左板沿侧轴、顶盖沿竖轴平移。三代表设备保持原朝向并沿相同前轴平移。这些位移只解释装配对应关系，不是实际行程、拆出顺序、安装、维修或热插拔程序。当前100%分离不声称内外轨仍相接或足以承载悬空设备。

设备内轨随机箱，外轨与前后端支承留在柜架安装位置；前端和后端对应前后安装柱。右下放大图取同一计算位在安装位置的单侧四个现有轨道/支承网格，省略外壳便于观察，未增加设备。左上与左中分别为同一计算代表和同一电源架代表的正面放大；放大仅重复现有八载盘/六模块，不新增实例。

六次内置 imagegen 已实际传入 R2、TA-13 母图和适用的原生几何参照，但局部修正持续造成7盘、5模块、盒体加宽或空位被填等回归，因此全部拒绝并保留本机原件、SHA、提示词及原因。最终采用规范允许的受控3D原生制作：`rack-exploded-generator.js` 独立原生1536×1024渲染，同尺寸原生局部1:1合成，未插值、未将当前交互快照当母图、未声称AI位图被采用。母图与交互使用同一程序几何；TA-13已验的AI整柜母图仍独立保留，不声称两图为像素一致原厂资料。

服务槽铜色长条与灰管仍为未连接的可选附件，归既有`rack-frame`上下文，不取得整流或配液身份，不连接风冷计算设备。单个计算/电源架/交换机档案继续说明本图示例数量和未知配置，类别研究链接不证明本实例的电气方案或供应者。原BOM与研究事实不改。

新`x=35`及显式`view=rack-exploded`只由独立通用分层几何负责，`explode=0..100`可深链指定展开比例。默认TA-13 `x=0`的598个网格、顶点、位置、旋转及类别逐一与旧源码比较；新图611个网格是原几何加虚拟门/左壳并重新归属固定外轨，不替换TA-11服务器或TA-15芯片视图。旧原厂面板、可选模型和历史分层通过显式`view=legacy&x=35`保留，相关既有资源/镜头测试随该明确入口继续验收。

整柜档案聚合全部实际几何；子部件普通点选仅聚合被选单个实例。当前视角SVG导出包含局部稳定实例ID、当前像素和视角，不能称为母图或CAD。实际桌面/手机明暗、0/100、缩放和点选导出逐项验收；机器计数与生成PNG不能代替逐张目检、实际公网下载和健康镜像回执。
