## 项目总方向（用户 2026-08-15 亲述，最高权威）

1. **研究对象**：AI/智算数据中心及其附属生态的深入研究。
2. **组织方式是 team work**：项目拆成**穷尽且互斥**的组件（模块），以后每个组件安排
   不同的人负责，各自独立运行更新——GitHub 式工作流：每人做好提交（PR），
   由用户基于整体安排 merge/否决，把各组件更新统一进 core。
3. **输出方式**：用户按需求随时导出想要的报告（PDF 等）。
4. **付费报告处理流程**：逐份阅读 → 打分 1-9 → 重命名归类到对应文档目录 →
   同步更新相关研究角度（= 现行 LIBRARY_SCORES.csv + 精读消化机制）。
5. **产品要求**：dashboard 要漂亮整齐；爆炸图要有良好漂亮的人机互动，
   能快速进入想探索的领域。

## 长期有效的原则（用户已确立，不随会话过期）

- **数据在变，框架不变**：15 模块 MECE 骨架稳定，数据持续流入，报告只是导出物。
- **口径纪律高于数据量**：容量（GW）/用电（TWh）/投资（$）/需求模型四种口径永不混加；
  只有通电投运（L8+）计入当期供给；官方未披露的 MW **不许**按面积/GPU 数/投资额推算——留白即纪律。
- **知识层（research/Mxx.md）是项目主体**，报告是导出物；Finding 必须可独立证伪、带触发器。
- **零依赖技术栈**：纯 Python 标准库 + JSON 数据层 + 单文件 HTML；与 news 项目共用基因，未来同上 VPS（wentian.ai）。
- **三线复用**：同一份数据资产服务决策、融资、公众号内容三条线。
- **二进制不进 git**：研报库本体留本地，索引（LIBRARY_INDEX.md）和打分（LIBRARY_SCORES.csv）进 git。
