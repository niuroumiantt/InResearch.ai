## 拟新增 M10-F? 中国数据中心主楼土建的单方造价约 2,088 元/m²（2016 湖南口径），机电配套后约 2,438 元/m²

- **状态**：draft ｜ **修订**：2026-08-16 ｜ **触发器**：indicators:dc_construction_cost_cny、periodic:365d
- **结论**：华为（永州）1#数据中心的土建造价为 **28,444,308.95 元**（建筑工程 20,094,338.78 + 装饰部分 8,349,970.17），清单中综合脚手架面积为 **13,623.95 m²**、平整场地 **7,755.8 m²**。按综合脚手架面积口径折算，**土建单方造价约 2,088 元/m²；再计入 1#安装工程 4,777,959.36 元后约 2,438 元/m²**（两个单方值均为计算值）。这是本库第一个中国数据中心的单方造价锚点——M10 此前在这个问题上只能引用二手估算。
- **论证**：
  - **面积口径是本条的主要不确定性**。原文没有直接给出建筑面积，13,623.95 m² 是「综合脚手架」的清单工程量。在湖南定额体系中综合脚手架按建筑面积计算，因此二者通常一致，但不排除局部差异（如层高超限部分另计）。正式引用前须用图纸建筑面积复核，标 **[口径待核]**。
  - **该单方造价只含土建与建筑机电，不含数据中心工艺设备与 IT**。它回答的是「盖这栋楼花多少钱」，不是「建这个数据中心花多少钱」，两者相差一个数量级。
  - 装饰占土建的比例可作为交叉校验：1#数据中心装饰 8,349,970.17 / 建筑 20,094,338.78 = 41.6%（计算值），而同项目的普通配套用房（2#主门卫）为 70.0%——**主机房楼的造价重心明显更偏向结构本体**，符合机房楼大跨度、高荷载、少内装的特征。

## 拟新增 M10-F? 湖南 2016 口径的费率体系不随单体规模变化，只随专业变化——外推的前提条件已验证

- **状态**：draft ｜ **修订**：2026-08-16 ｜ **触发器**：periodic:365d
- **结论**：本项目十八册预算书用的是同一套费率，且**费率只随专业（建筑/装饰/安装）变化，不随单位工程规模变化**——从造价 20,094,338.78 元的主楼建筑工程到造价 214.42 元的门卫给排水，费率逐项一致。这条已验证的性质意味着：**这套费率可以外推到同期同省的其他项目做造价估算**，而不必担心规模效应。完整费率如下（可直接落库）：
  - **建筑工程**：管理费 **2.333%**、利润 **2.542%**（基数均为「取费人工费 + 取费机械费」）、安全文明施工费 **13.18%**、冬雨季施工增加费 **0.16%**；
  - **装饰工程**：管理费 **2.648%**、利润 **2.888%**（基数为「取费人工费」）、安全文明施工费 **14.27%**、冬雨季 **0.16%**；
  - **安装工程**：管理费与利润同以「取费人工费」为基数，另设「专业措施项目费」科目（本项目为脚手架搭拆费）；
  - **规费（五项，全专业统一）**：工程排污费 **0.4%**、职工教育经费和工会经费 **3.5%**、住房公积金 **6%**、安全生产责任险 **0.2%**、社会保险费 **3.18%**；
  - **税**：销项税额 **11%**、附加税费 **0.36%**。
  - 依据文号：湘建价【2016】160 号（营改增）、湘建价【2014】112 号、永财办【2015】4 号，材料价取永州市造价站 2016 年第 5 期。
- **论证**：
  - 规模跨度检验：1#数据中心建筑工程（20,094,338.78 元）与 3#次门卫建筑工程（74,725.44 元）相差 269 倍，管理费 2.333%、利润 2.542%、安全文明 13.18% 三项完全一致；安装侧 1#电气（826,732.20 元）与 2#门卫电气（7,645.56 元）相差 108 倍，规费五项费率逐项一致。
  - 专业差异检验：建筑与装饰的管理费/利润/安全文明分别为 2.333%/2.542%/13.18% 与 2.648%/2.888%/14.27%，且**计费基数不同**——建筑用「取费人工费 + 取费机械费」，装饰用「取费人工费」。这个基数差异比费率数值本身更容易出错，估算时必须一并带上。
  - 人材机结构（计算值，可作为分专业的经验比例）：建筑工程材料 62.6% / 人工 29.6% / 机械 7.8%；装饰工程材料 56.3% / 人工 42.6% / 机械 1.1%；电气安装材料 75.9% / 人工 19.9% / 机械 4.1%；气体灭火与消火栓喷淋材料 79.6%；给排水（小单体）材料高达 89.6%。**越靠近「设备采购」的专业，材料占比越高，人工与机械占比越低。**
- **证据**：
  - [S2/业主招标文件原件] 本地文件 `8A_2016_华为永州1号楼建筑预算_永州开发投资.xls`（附 D 新表 D.3 费用计算表，费率与计费基础说明逐行原文）
  - [S2/同项目十七册] 5A/4A 门卫各册与安装各册（见 batch_20260816_22），费率一致性即由这十七册逐项比对得出
  - [S2/依据文号] 湘建价【2016】160 号、湘建价【2014】112 号、永财办【2015】4 号（见招标控制价总表编制依据栏）
- **口径提醒**：
  - 「费率不随规模变化」是**在本项目内部验证**的结论，推广到其他湖南项目时仍属合理外推而非已证事实，标 [外推]。
  - 安全文明施工费的计费基数在建筑（人工+机械）与装饰（仅人工）之间不同，**同一个 13.18% / 14.27% 不能互换使用**。
  - 销项税 11% 是 2016 年营改增过渡期税率，2019 年后已降至 9%（见本库 `7A_2019_移动南方基地通风空调控制价_中国移动.xlsx`，广东 2019 项目用 9%）——**这两份材料合起来可以直接量化税率下调对造价的影响，是难得的同库对照**。
- **待办**：把这套费率整理进 framework 的中国造价口径附录；与广东口径（移动南方基地 2019、移动粤港澳 2022）做费率体系对照——初步已见广东独有「绿色施工安全防护措施费」（费率 35.77% / 19%）与「预算包干费」科目，湖南口径中没有。
