# 管理后台加载修复 · 2026-10-08

## 用户目标与故障

用户要求管理后台直接展示指标、工作进展、pending、长期错误和瓶颈；实际公网浏览器停在加载，随后显示超时/英文 aborted。原 `/api/ops` 返回约10.13MB，reader.acquisition 中约9.72MB为首屏未使用的日报/事件/匹配/交付明细。首屏 defer 脚本与尾部内联脚本另受字体样式和附加表读取拖延。

## 当前实现

- 仍按现行接收验证与身份规则读取快照，管理投影在缓存前只保留健康、指标、有限诊断样本、点名批次和采集来源汇总。其他页面与原始运行快照保留。
- 管理API按Accept-Encoding提供gzip；禁用gzip时返回同一JSON，响应private/no-store。原管理员门禁保留。
- 页面尾部两个异步脚本分别启动dashboard和附加表单；无inline/defer脚本等字体样式。账户表、价格自动补全和生成物表只在展开后读取。
- 20秒真实AbortController超时显示中文，刷新按钮恢复；首次失败的各区块显示未知，已读过的数字保留但明确未确认。

## 验收与发布

本地接口/治理/严格校验与registry通过；浏览器dashboard通过按需读取、字体CSS持续等待仍显示导航与指标、真实abort中文/刷新恢复、有限样本身份、安全渲染、明暗及窄屏。全站23页面外观回归通过。规范与验收映射已人工复审并刷新清单。

发布须通过本PR CI、现有AWS独立部署服务，并用真实公网管理员只读浏览器验证首次加载、刷新、任务筛选、附加表和完整指标，不能用夹具或容器healthz代替。最终运行版本、响应大小与截图回执记录在本PR描述中。本轮不操作Spark Reader任务/模型/原件，不宣称系统已有阻塞被解决。
