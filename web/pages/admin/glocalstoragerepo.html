# Glocal Storage 官方网站

## 项目简介

Glocal Storage 是一个基于 Flask 的企业级网站项目，提供半导体存储产品展示、解决方案和技术支持等功能。

## 技术栈

- **后端**: Flask 3.1.3
- **前端**: Bootstrap 5, jQuery
- **Web服务器**: Gunicorn（容器内监听 :8080）+ Caddy（宿主机唯一对外入口，自动 HTTPS）
- **部署平台**: AWS Lightsail 合并主机 `Inresearch.ai`（32.193.21.111），docker compose 服务名 `glocal`

## 主要功能

### 1. 产品中心
- DRAM 内存模组（支持多维度筛选）
- NAND 闪存
- SSD 固态硬盘
- CIS 图像传感器
- CXL 互联技术
- MCP 多芯片封装

### 2. 解决方案
- 应用方案展示
- 技术支持
- 常见问题解答

### 3. 响应式设计
- 桌面端：完整导航菜单（带下拉菜单）
- 移动端：优化的一级菜单导航
- 自适应各种屏幕尺寸

## 安装和运行

### 本地开发环境

```bash
# 1. 克隆项目
git clone https://github.com/niuroumiantt/glocalstorage.com.git
cd glocalstorage.com

# 2. 创建虚拟环境
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行开发服务器
make run

# 访问 http://localhost:8080
```

默认开发服务器只监听 `127.0.0.1`。如果确实需要让局域网设备访问，可临时使用 `HOST=0.0.0.0 make run`。

### 生产环境部署

生产环境没有手动部署步骤：**push 到 `main` 就是部署**。

```text
git push origin main
  → 服务器 autopull（每 2 分钟）拉取 /srv/glocalstorage.com
  → docker compose 重建 glocal 容器
