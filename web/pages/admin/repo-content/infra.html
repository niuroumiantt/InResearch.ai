注解 · 网络与访问控制（hosts/tailscale/policy.json）

  • autogroup:admin（站长的设备 m5 / m4 / macmini）可达任何机器任何端口；生产机 SSH 别名见 scripts/mac_tools.py：aws 用 ubuntu + pem，aliyun 用 deploy + ed25519，root 与密码登录已关。
  • tag:prod-server（aws）只能打 100.100.1.2:11434，用于 inews 标题翻译；这是家用机器进生产路径的唯一口子，且是跨境链路。
  • tag:aimail（aliyun）只能打 100.100.1.2:4000（LiteLLM HTTPS）；直连 :11434 实测超时（被拒）。
  • autogroup:member 可达 100.100.1.2:443（Open WebUI）。
  • 家里 ASUS 路由器 192.168.50.1 做 DHCP 保留，零端口转发；aliyun 主机 DNS 固定 223.5.5.5 / 223.6.6.6 并保留 Tailscale 解析器。
