# Semifly 站点仓库

本仓库是 Semifly **三个站点的唯一源**(source of truth):线上 Lightsail 服务器从这里自动拉取并部署。

> **协作与上线流程以 [GOVERNANCE.md](GOVERNANCE.md) 为准**(多窗口分工、唯一远端、上线步骤、事故记录)。
> 本 README 只做总览;凡涉及流程的问题,先读 GOVERNANCE。

## 站点构成(三站一仓)

| 站点 | 目录 | 线上地址 |
|---|---|---|
| 主站 | `semifly/site/` | https://semifly.ai |
| LLM 频道 | `semifly/site/_llm/`(数据+构建) ＋ `semifly/site/llm/`(页面) | https://semifly.ai/llm |
| Marketplace | `semifly/marketplace-site/` | https://marketplace.semifly.ai |

三站同属一个 Git 仓、一套文件,靠**子目录归属 + 纪律**隔离(见 GOVERNANCE §一/§二)。
共享层(页眉/页脚/全局 CSS/字体/菜单/搜索)在 `semifly/site/_semifly/`,由 MASTER 窗口独占维护,其它窗口只读。

## 部署流程(简版)

本地 Mac 改好 → MASTER 推工作分支并开 PR → GitHub(`niuroumiantt/semifly.ai`, private) 合并进 `main` →
线上服务器约 2 分钟自动拉取(`deploy/autopull.sh`:先校验候选版本,通过后 `git reset --hard`) →
nginx 直接服务静态文件(主站 root = `semifly/site`,Marketplace 为独立子域)。

- **唯一远端是 `deploy`**(= GitHub 私有仓 `semifly.ai`),它就是线上拉取源;该仓 2026-06-26 由旧名 `semifly20260611` 改名并转 private(旧的近乎空的 `origin` 仓已弃用)。
- **唯一上线出口是 MASTER 窗口**;所有 git / 部署只在 Mac 本机终端执行。
- 服务器 / 部署脚本都在 `deploy/`(`setup_server.sh`、`autopull.sh`、`mirror-images.sh` 等)。
- CI 门禁在 `.github/workflows/ci.yml`:重建生成物并运行 `semifly/tools/quality/run_all.py`;服务器部署也运行同一质量门禁。

## 质量与构建入口

```bash
python3 semifly/tools/quality/run_all.py      # 语法/JSON/XML/sitemap/链接/SEO/遗留引用检查
python3 semifly/tools/build/build_all.py      # 重建 LLM、Marketplace X86 与 catalog,并跑质量检查
python3 semifly/tools/build/build_all.py --check --skip-quality  # CI 用:检查生成物是否已提交
```

当前策略:语法、结构化数据、sitemap、搜索索引等是 **ERROR**;历史内容债(旧链接、重复标题、遗留第三方引用等)先作为 **WARN** 暴露,逐步清理后再提升为严格门禁。

## 自动化:LLM 新闻机器人

`.github/workflows/llm-news.yml` 每天抓取 LLM 新闻、重建 `/llm` 页面,**推到 `auto/news` 分支并开 PR**
(绝不直推 `main`),由 MASTER 审查合并后才上线(见 GOVERNANCE §七)。

## 本地预览

```bash
./start_local_server.sh        # 转调 tools/scripts/,默认端口 8002
```

然后访问 http://localhost:8002/ 。也可直接用 `tools/servers/` 下的 Python 脚本启动。
(根目录的 `tools`、`site` 等是指向 `semifly/` 内部的符号链接,兼容旧路径。)

## 维护指引(按归属改对应目录)

- 主站内容 → `semifly/site/` 下 HTML
- 共享页眉/页脚/菜单/搜索 → 只动 `semifly/site/_semifly/`(MASTER 域)
- Marketplace → `semifly/marketplace-site/`
- LLM 频道 → `semifly/site/_llm/` + `semifly/site/llm/`
- 产品图:通过 `deploy/product-images.tsv` 清单在部署时抓取(`mirror-images.sh`);抓不到的少量已入库兜底

# 仓库目录布局（维护用）

```
semifly/                   # GitHub 私有仓名: semifly.ai
├── semifly/
│   ├── site/              # 主站静态产物（根目录 site → 此处）
│   ├── marketplace-site/  # Marketplace 静态产物
│   ├── tools/             # 质量门禁、统一构建、本地服务、维护脚本、semifly-dev
├── site  → semifly/site
├── tools         → semifly/tools
├── _devtools     → semifly/tools/semifly-dev
├── docs/                  # 文档与截图；reports/ 放本地 .txt 报告
└── README.md
```

- **不要改 `semifly/site/` 内页面相对链接**，除非你知道影响范围。
- **主站启动**：`./start_local_server.sh` 或 `python3 tools/servers/semifly_server.py`。
- **质量门禁**：`python3 semifly/tools/quality/run_all.py`。
- **统一构建**：`python3 semifly/tools/build/build_all.py`。
- 根目录 **`site` / `tools` / `_devtools`** 为符号链接，便于旧文档与脚本路径继续有效。
- 旧的 `archive -> semifly/archive` 符号链接已移除；仓库内不再保留任何原始克隆镜像入口。
