月牙圆点 / 独立 i

浅底使用

暖白底优先使用彩色透明字标。不要给 Logo 加白色矩形底板，不要重新打字替换字标。

  • 品牌橙：#FD340A
  • 墨黑：#0B0C0C
  • 暖白：#F6F5F2

深色与蓝黑底

使用反白透明版本，in 与 .ai 保持品牌橙，research 使用暖白。月牙保留透明负形。

  • 蓝黑：#101820
  • 研究文字：#F6F5F2
  • 保持安全区与原比例

02 / Typography

中文和中文全角标点使用仿宋；英文、数字和 ASCII 标点使用 Source Serif 4。

内容字体执行要求
中文、中文全角标点FangSong / 仿宋Regular 为正文基准；标题可用真实字重，不使用伪粗体。
英文、数字、ASCII 标点Source Serif 4正文 Regular；英文标题与重要数字可用 Semibold。
代码、ID、日志IBM Plex Mono保持固定字符宽度，便于技术信息对齐。
混排空间按语境切换中文语境标点跟随仿宋；英文语境标点跟随 Source Serif 4。

03 / UI & Icons

UI 以清晰层级、低噪声边界和研究工作流为核心；功能图标保持统一线性语义。

04 / MarComm

对外材料要保持同一品牌语气：清晰、可信、留白充分，所有业务数据和联系人字段发布前必须替换并核对。

常用材料

  • 正式信纸与公司介绍
  • 邮件签名：浅色 / 深色
  • 社媒方图、横图、竖图
  • 网页横幅与品牌图形

发布前检查

  • Logo 使用正确版本与背景对比度
  • 中文、英文、数字字体分工正确
  • 事实、日期、来源和授权已核对
  • 导出 PDF / SVG 时保留清晰路径
