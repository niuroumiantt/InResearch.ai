# 按需输出 — 使用说明（2026-09-28）

> 成果 = 树的可发布快照，由权威文件生成，不另写第二份事实。三种导出。

## 三种导出

| 形式 | 怎么得到 | 内容 |
|---|---|---|
| Markdown | `python3 manage.py export` → `reports/output/<日期>_datacenter_snapshot.md` | 封面可信边界 + 四章即四问 + 专题目录 |
| JSON | 同一命令的 `.json`，或 `/api/report` | 同一快照的结构化形式，供外部客户端 |
| 打印 / PDF | `report.html` 浏览器打印 | 页面打印样式，去顶栏与目录 |

兼容模块的研究结论（15 章 150 条）仍可整卷导出：`python3 manage.py export --legacy [--docx] [M08 M09] [--title ...]`；页面在 `report.html?legacy=1`。

## 提新的输出需求

用一句话描述"角度 + 形式"。角度只能用唯一逻辑的词汇：骨架节点（系统 / 链路 / 部件 / 权利 / 主体）、五类变量、四问、目标行 ID；不再按模块编号或视角组织。每个需求变成一个生成器，写一次以后同样角度随时重跑最新登记。

## 口径纪律（自动继承）

数字可溯源到登记表记录；混合口径拆列标注；推算值附公式与假设；规划容量不得写成投运规模；视图层不填估值；登记数只标"登记数"。详见《口径与核验规则手册》。
