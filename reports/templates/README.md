# reports — 输出层（L3）

报告是**数据 + 模块视图**的按需渲染结果，不是手写文档。输出物按"受众 × 载体"矩阵组织：

| 受众 | 输出物 | 载体 | 频率 |
|---|---|---|---|
| 自己/内部决策 | 监测仪表盘、瓶颈预警 | index.html / Excel | 周/月 |
| 投资人/合作方 | 深度研报、专题分析 | PDF / Word | 季度 + 事件驱动 |
| 路演/会议 | 行业格局与情景 | PPT | 按需 |
| 公众号读者 | 产业解读文章 | HTML 排版 | 周/双周 |
| 客户/商务 | 定制数据切片（某区域/某环节） | PDF / Excel | 按需 |

## 报告的固定骨架（继承口径纪律）

1. **执行摘要**：十大核心判断（每条真的只有一句话）+ 情景一页图
2. **方法论前置**：口径定义、状态分级、去重规则——一次讲清，正文只引用
3. **模块正文**：按需选取 M01–M15 的最新视图，每个大数字引用库内 record
4. **情景与监测**（M15）：三色仪表盘 + 漏斗 + 情景权重，作为收尾件
5. **附录**：数据表切片 + 来源清单（分级标注）

## 生成方式（规划）

- 模板放本目录（Markdown 母版 + 各载体转换配置）
- 生成脚本读六张表 + modules.json → 填充模板 → pandoc/python-docx/pptx 转目标格式
- 产出落 `reports/output/YYYY-MM/`，带数据快照日期，可复现
