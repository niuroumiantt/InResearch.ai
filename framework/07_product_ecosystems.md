# 产品生态、研究深度与总览

> CURRENT · 最后更新 2026-09-06 · 架构 2.1.0。替代“产品类别、技术、介质混在同一节点”及节点八组混合内容契约的相关口径。实现与部署分别验收。

## 入口与身份

全站硬件提供八个产品生态入口：存储、计算与加速、内存、网络与互联、电力与供配电、冷却与热管理、设施与机柜、控制与运维。八类是现有登记对象的主浏览地址，不宣称天然穷尽未来产品；现有每个硬件节点必须有且只有一个主生态。跨生态用研究关联引用，不能复制对象。

P/F/V/D/R 保留为观察视角。空间目录、产品生态、内部部件、指令集架构、厂商和型号是不同维度，不能强制成为同一棵装配树。生态和技术话题不是物理部件，软件不是存储介质，概念研究入口不能证明现场实装。

声明唯一来源为 research_graph.json 的 hardware_domains、对象 research_sections、research_topics 和 catalog_topic_mappings。首页、产品目录、园区/机柜 3D 的产品生态入口及研究工作台使用这些身份。3D 几何精细化另行实施，本次不虚构新的可视模型。

## 不同产品采用不同深度

| 生态/产品 | 当前研究范围与展开方式 |
|---|---|
| 存储生态 | 软件与数据服务、访问/部署方式、存储系统、SSD/HDD、内部器件、接口协议 |
| SSD | 整盘产品 → 控制器、固件/FTL、NAND；企业级/消费级为用途分类，不与协议或外形混为一层 |
| NAND | 作为独立技术与产业话题，分别研究单元类型和工艺/制造；保留独立市场统计口径 |
| CPU | x86、Arm、RISC-V 为主要指令集入口；其他架构保留既有产品入口。本阶段不展开内部电路 |
| GPU/AI 加速 | GPU 与专用 ASIC 分开；GPU 按 NVIDIA、AMD、其他厂商架构研究，厂商/型号通过目录关联 |
| 内存 | HBM、GDDR、LPDDR、DRAM 模组独立研究；按具体配置连接 CPU/GPU/平台 |
| 网络、电力、冷却、设施、控制 | 保持主要产品与系统接口层级，有具体问题和证据后再深入，不机械复制 NAND 的拆分深度 |

SSD 控制器是控制芯片，NAND 是介质；二者不作同义词。HBM/GDDR/LPDDR 不是所有 GPU 的固定内部子件。例如 NVIDIA Grace 文档中的 LPDDR5X 为 CPU 配套内存；统一内存与独立显存、CPU 内存必须按型号和配置辨别，不能直接相加或据名称推断装配。

背景定义参照 [SNIA SSD](https://www.snia.org/education/what-is-ssd)、[RISC-V 规范](https://riscv.org/specifications/ratified/)、[AMD 架构文档](https://rocmdocs.amd.com/en/latest/conceptual/gpu-arch.html)、[NVIDIA Grace 文档](https://docs.nvidia.com/dccpu/grace-perf-tuning-guide/index.html)。这些背景链接不是 C3 已采用证据。

## 历史节点和产品映射

`part:ssd` 保留为“SSD / NAND 历史合并入口”，旧问题、证据、BOM 和 3D 链接不失效。新增 `part:ssd-drive`、`part:nand`、`part:ssd-controller`；旧记录未经核验不自动转移。`part:gpu` 继续保留 GPU 与 AI 加速器的原有广义范围，通过新产品/技术入口细分。

产品目录继续保持产品线身份和原始记录；新增主题映射只依据既有目录标签，显示为待核实目录，不自动证明 SKU 规格、厂商能力、兼容性或实际安装。历史来源里的混合产品线不能直接当成同口径的厂商份额。目录补全和旧证据逐项映射是后续研究任务。

## 产品与行业总览以及九主题

默认进入总览；显式旧 tab 链接保持行为。总览展示简介、进一步研究入口、背景出处、九主题提纲以及报告入口。资料缺失时保持待补，不能生成已核实的市场结论。问题/材料/证据/陈述/答案/任务是记录类型，不是互斥行业主题。

九主题固定为：T01 定义与边界；T02 结构与技术；T03 应用与需求；T04 性能与选型；T05 市场规模与周期；T06 生产与供应链；T07 厂商与竞争；T08 价格、成本与商业；T09 部署、运维与约束。

每个原子问题一个主主题，跨主题引用；复合问题拆开。市场总收入归 T05、单位 ASP 归 T08、份额归 T07、产能归 T06；计算结果保留依赖。时间、地域、配置、风险与趋势贯穿各主题。待分类不等于不适用，也不算完成。本次新节点登记 T01 边界问题；其余专题及历史问题尚未全量映射，页面明确显示待补，不伪造九主题完成度。

总览将来引用证据和答案形成综合介绍，不建立第二套独立事实。报告原件只存一次，按页/节/表/单元格关联多个话题；每次更新保留统计期、发布时间、实际/预测与修订身份。用户的 Yole 文件本次未完成本地读取，不因附件名称而宣称已读或引用其数字。

## 厂商阅读导航

产品栏顶部按当前匹配厂商建立可搜索、可点击定位的索引，产品按厂商聚集，分页隐藏的目标先展开再定位，支持键盘焦点。当前使用名称与产品线数量；未取得来源明确的 logo 不伪造品牌图。多厂商集合继续标明厂商组，不伪装为单一品牌。后续真实标识沿用全站资产登记规则。

## 更新和验收

架构变化同步正式文档、图与问题版本、页面、产品映射校验和当前登记。主规范文件名保持稳定并标最后更新日期；讨论、评审、交付快照以 YYYY-MM-DD 开头，同日需要时加时间。日期仅帮助识别版本，现行/已替代状态决定执行依据。删除无独立价值的旧说明前修复引用；研究原件、事实历史和反证不随规则替代删除。

本次实现覆盖入口、导航、总览结构、厂商定位与明确的分类身份。专题综述、型号架构核验、旧材料归属与真实 logo 尚需补充，不能将结构上线当作研究内容完成。
