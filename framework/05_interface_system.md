# 05 · 全站界面与外观规范

> CURRENT · 2026-09-28 · 取代「总览 / 研究 / 资料 / 任务 / 成果」的工作流式一级导航、八生态与 9 × 5 矩阵的节点页文案、按 07 产品生态实现的对象图谱；也取代「Attio / folk 两套可切换视觉」、逐页硬编码色板、全站禁用圆角及仅以暖色卡片表达 folk 的旧解释。现行依据见 [CURRENT](CURRENT.md)。

## 一套业务，一套视觉，两种明暗

2026-09-22 起全站只有一套视觉：线条式，直角内容块、细深色外框、胶囊操作、文字选项卡细底线；明暗独立选择。此前的 Attio / folk 切换是开发期的 A/B，布局完全相同，只在圆角、边线深浅和按钮颜色上有差别，却让每条规则写两遍；内部研究工作台的用户不需要在两种外观里选。切换器从顶栏移除，偏好里旧的 `skin` 字段忽略。

令牌只在 `web/themes/site-skin.css` 定义并由本仓库拥有，不再内嵌 infra 的 CRM 变量块；页面消费 `--ui-*`，旧别名只作兼容。

| 项目 | 规则 |
|---|---|
| 标题 / 正文 / 辅助 | 三层暖墨色，直角内容块，较舒展标题 |
| 外框 / 内行 | 细深色外框、弱色内行 |
| 面板 / 输入 / 操作 | 0 / 2px / 胶囊；面板间保留 18px 间距 |
| 导航与组织 | 单色操作、文字选项卡细底线，不把所有导航做成胶囊 |

## 字体：全站共用 infra 字体包

字体由 [infra/design/fonts](https://github.com/niuroumiantt/infra/tree/main/design/fonts) 统一：拉丁与数字 Inter，汉字 Noto Sans SC，两款都是 OFL 许可、自托管、按 unicode-range 切片。目的是同一段中英混排在 Mac、Windows、Linux 和手机上长得一样；之前的「系统中文回退」做不到这一点。

- 字体包用 `python3 scripts/sync_fonts.py --target web/assets/fonts` 从 infra 原样同步到 `web/assets/fonts/`，`manifest.json` 记每个文件的 sha256，单测校验本地文件与清单一致。
- 每个应用页与认证页在共享外观之前加载 `/assets/fonts/fonts.css`，并预载首片 `noto-sans-sc-1.woff2`。页面、组件和 3D 画布标签的字体一律指向共享字体栈，不再自带 PingFang 一类系统字体栈。
- 字体包目录整体为登录前可公开资源（含许可证），与外观 CSS/JS 同一边界。
- 字号字重底线：正文 14 px、元信息 13 px，不用 12 px 以下的汉字；标题 600、强调 550 或 500、正文 400；数字列用 `tnum` 等宽。

## 表单控件

`select`、`checkbox`、`radio`、文本输入和 `textarea` 的外观由共享外观统一：去掉浏览器原生皮肤，直角、细控件色边线，深色主题自带反色图标。规则用 `:where()` 保持零特异性，页面里有明确意图的局部样式仍能覆盖；顶栏的外观下拉框用同一套规则，不再露出操作系统原生样式。不引入组件库。

图标为本项目自有 SVG 线条几何。分类、排序、证据、任务状态及权限不随外观变化。功能复杂度仍由业务决定，不以参考网站的宣传插画替代真实内容。

## 顶栏与明暗

顶部统一显示 inresearch.ai；一级导航为行业总览、数据中心研究、账本、爆炸图、采集、成果，管理入口按角色出现（见下节「目录」）。实习生只显示采集入口（自己的目标行）；公开只读角色显示行业总览、数据中心研究、爆炸图、成果与账本（账本只见基准预设）；认证页只显示品牌与外观。各页面保留与当前内容相关的局部视图和操作，不再各自维护一级导航。

右侧只有“外观”下拉框；窄屏下品牌与外观一行、一级导航一行，顶栏不超过两行，一级导航单行横向滚动。顶部实际高度由共享组件测量，页面和 3D 控件使用同一个偏移量。

明暗选择浅色 / 深色 / 跟随系统，默认浅色。只有选择“跟随系统”才响应操作系统明暗变化。

统一令牌位于 `web/themes/site-skin.css`，全部应用页使用同一文件；旧 CSS 变量只作为兼容别名，不再各自定义色板。颜色、边界、字重、间距随明暗切换。不得在单页重新添加 `prefers-color-scheme` 色板或全局强制圆角规则。

偏好存于当前浏览器同源 localStorage（`inresearch.ui.v1`，只含 `mode`），跨页面、刷新及同源标签页生效；不跨设备同步，不写入研究数据或账号权限。存储不可用时本页仍可切换，并提示偏好未保存。脚本在首次绘制前设置根节点属性，降低错误色系闪现。`<html>` 上的 `data-ui-skin` 属性保留为「共享外观已接入」的标记，值固定，不再表示可选风格。

目录项与四问的对应登记在 `interface_manifest.json` 的 `section_questions`，单元测试与本表对账（2026-09-29）。"一个模板"只指节点页：`node.html` 是 dashboard（任一节点 × 五列 × 四问）的唯一模板；账本、爆炸图、规格库、主体、采集、成果、管理各是某一列或某一问的展开页，不从 `node.html` 派生，登记在 `sections` 里。

四个读法入口各落到一列或一页：它怎么建 → `node.html?col=4`（按建设阶段排，从站点权利起，链账本的建设输入）；它由什么组成 → `bom.html` 与 `node.html?col=1`；它怎么运转 → `node.html?col=2` 与 `ledger.html#ledgers`（运营支出在四本账里）；它挣不挣钱 → `ledger.html#ledgers`（四本账含 IRR、DSCR、杠杆现金回报）。

角色四种：admin、member、intern 与公开只读的 reader（2026-09-28 采用）。reader 不登录即可 GET 行业总览、数据中心研究、爆炸图、成果与账本基准预设，不能改输入、不能见地区预设、不能见采集页与目标行来源 URL；服务端按角色过滤字段，不只在前端隐藏。白名单实现在 `src/inresearch/interfaces/public.py`，界面清单 `interface_manifest.json` 的 `sections`（每页归属的目录项）与 `public_pages`（reader 可看的页）与之对账；登录的实习生也能看 reader 能看的内容。

## 页面与 3D 范围

[界面清单](interface_manifest.json)列出全部应用页面和明确例外：18 个交互页面以及登录、改密、无权限页面接入共享外观。海报/打印交付物、开发烘焙工具、未采用提案原件保留各自用途；打印报告隐藏换肤栏并使用浅色纸张样式。

园区与机柜 3D 的控件、背景及雾色随明暗变化。模型材质、覆盖率颜色、物理语义、相机和选中对象保留，避免视觉偏好改变研究含义。切换不重载页面，不重建业务数据。

两交互场景的 HDR、PMREM target 与 CanvasTexture 由 `scene-resources.js` 统一持有。页面只声明环境配方和纹理绘制内容；失败或超时保留程序化视觉，旧加载不能在重试或退出后夺回环境。替换释放旧 target，pagehide 停止渲染并释放环境、纹理池、composer 和 renderer。离线 bake 工具与比较台的短生命周期另行保留，不冒充已迁移。

登录前仅公开不含业务数据的外观 CSS、JS、Inter 字体与许可。所有研究数据、其他静态文件和 API 保持原权限边界。

## 新页面与验收

### 统一经济模型与账本（2026-09-28）

`ledger.html`（账本）是根节点价格列的唯一展开，也是数据中心经济模型唯一的页面。它读取 `data/datacenter_model.json`（统一经济模型 v3）：一份输入表按五类变量分组（构成、运行、价格、时间、主体），每个输入带证据状态（用户给定、已有来源、作者假设、待获取）与变量类；地区是一组制度参数的预设（美国弗州、美国得州、内蒙古、柔佛），每个地区登记 `gaps` 列出还没有登记来源的键，页面标「缺」；代际、冷却、上架类型、单价路径、承租人信用是同类的表。基准只有一个（`presets.baseline`），每个数取有登记来源的值：PUE 由冷却方式的登记值决定，电价取价格库弗州工业电价最新点，需量 14.5，土地 1.2；三家机构的算例（摩根士丹利 1GW GB300 出租、高盛 15% 回报门槛、我们 2026-09-14 的全成本基准）登记为校准预设，页面顶部的校准表逐项比对登记值与模型值。

引擎只有一个：`src/inresearch/knowledge/economics.py` 是参考实现，`web/components/datacenter-model.js` 逐行镜像，`tests/unit/test_model.py` 用同一份输入表在 node 里跑镜像并要求每个数与 Python 相等，并断言三个校准锚（229 亿 / 121 亿 / 31%；11.6 亿/GW 与 34.7% EBIT 利润率；1,167,777,119.40 与 4.10）。三种问法共用同一段代码：正算（等待期 → 建设期 → 运营期逐年现金流，负载爬坡与利用率爬坡分开，折现、平准化、四本账、每有效设备小时全成本）、反算（目标 ROIC → 需要的收入、单价、利用率或造价上限）、情景网格（造价/GW × 单价 × 利用率 → ROIC，标出两家的锚）。回报分母默认用摩根士丹利的总资本开支，高盛的平均年资本开支作可切换项。持有方式含 BOT（业主持地与壳，机电由合作方按服务合同回收）；制度门槛（电力 / 芯片）、门槛等待、审批期、能耗配额作为时间与构成类输入进入交付周期与可建容量。

页面下半部分是四个视图：成本结构与平准化（原 TCO 页）、四本账（原经济模型页）、每有效设备小时全成本（原成本计算页）、反算与情景网格（新）。`economics.html`、`tco.html`、`cost.html` 三个地址由路由表指向账本，页面按地址落到对应视图；三个页面的文件、组件、样式与模型 JSON 已删除，`docs/research/` 下的参考实现只作历史。交互只存在于浏览器当前状态，不改写研究权威；市场基准只登记 `benchmark_series`，前端从 `data/prices.json` 取最新时点并标注来源等级与时点；图表用内联 SVG 与共享令牌绘制，不引入图表库。验收（`tests/datacenter_tco.cjs`、`tests/datacenter_economics.cjs`、`tests/datacenter_cost.cjs`）至少核对：旧地址落到对应视图、基准每 kW·月、校准表全部复现、摩根士丹利预设 30.9% 与 $3.57/h、分母口径切换、2026-09-14 预设 $1.168B 与 $4.10、高盛预设 $11.65B/GW、网格 5 × 5 带锚点、地区切换与「缺」标记、内蒙古 BOT 与芯片门槛的交付周期、造价拆分方式切换、托管口径、数据缺口表、价格库对照及窄屏边界。

新增 HTML 必须在界面清单登记为应用页或写明排除原因；应用页在 head 同步加载共享 JS，并在本页结构样式之后加载共享 CSS。页面负责布局与业务，共享外观负责视觉规则。

验收包括浅色与深色、字体包已加载且正文字体栈以 Inter 与 Noto Sans SC 开头、表单控件已去原生皮肤、移动宽度与顶栏两行、键盘焦点、偏好保存及跨页/跨标签同步（含旧偏好里的 `skin` 字段被忽略）、研究节点与筛选状态保留、3D 背景切换、登录前资源边界（字体包公开、其余不公开）及打印隐藏。`node tests/run_browser.cjs` 启动隔离本地服务并执行全套浏览器回归，CI 安装固定版本 Playwright/Chromium 后运行同一入口；本机可设 `UI_BROWSER_CHANNEL=chrome`。检查实际内容、按钮对比、组件圆角及整页溢出，不能只检查外观下拉框。

对象关系图只按骨架身份（系统、链路、部件、站点权利、主体）显示一跳关系，邻居按 `bom.json` 与 `site_rights.json` 登记的 ID 过滤。图形沿用共享外观的颜色与直角，切换明暗无需刷新；最终 SVG 解析并保存当时的样式，不依赖网站 CSS。

### 数据中心节点页（2026-09-28）

`node.html` 是 dashboard 的唯一模板：一棵树（数据中心 → 五个系统，IT 展开四个子系统 → 系统内按链路 → 部件；站点权利并列）、五列（五类变量）、四问（它值多少、它由什么组成、它怎么影响账、数据从哪来缺什么，即四段倒序）。`?id=root | system:<系统> | part:<部件> | site | site:<权利>` 选节点，`&col=1–5` 停在一列。页面只读 `data/dashboard.json` 快照与目标表，不做聚合；取值来源登记在 `framework/dashboard_rules.json`，快照由 `python3 manage.py dashboard --refresh` 生成、`--check` 与单元测试保证一致。根节点顶部是三级账（成本、收入、回报，回报是账的输出不是一列），由 `knowledge.economics` 按统一模型基准预设计算，与页面 JS 同一公式，旁边固定角标：模型状态、作者假设数、无依据输入数、地区缺口，与部件缺口分开。"它由什么组成"在根节点是矩阵：五系统 + IT 四子系统 + 站点权利，折叠 6 行、展开 10 行，每格一个数与数据状态色，没有登记来源的格显示"缺"不显示估计值；系统的时间列取部件交期最大值（关键路径）；系统节点的部件表按链路分段。根节点第四问承载新闻时间线与派工面板（派工只读目标表）；部件节点第一问承载问题、候选证据、陈述与一跳关系，按骨架 ID 过滤。2026-10-02 起 `/` 与 `/index.html` 指向独立行业总览；节点研究保留在 `node.html`，替代此前首页退役的路由决定。

格级诚实规则五条（写进 `dashboard_rules.json`）：视图层不填估值；有值格写"数值 + 时点 + 队 · 目标行 ID"；无值格写"缺 · 待某队 · 行 ID · 到期日"；作者假设单独标"假设"；供应商数与产品线数只标"登记数"不算已采集；份额推算标明推算来源，不落在部件价格格里。

验收：矩阵折叠 6 行、展开 10 行 × 5 列；点格进入系统并停在该列；部件页四个面板齐全；根节点有三级账、四个读法入口、新闻时间线与派工面板；无页面错误；另接入共享外观验收。

### 厂商浮层（2026-09-06 更新）

产品图谱的厂商浮层采用细线边框、无阴影、无大标题的纵向名字列表；每行一个厂商，使用普通文字与细分隔线。替代此前胶囊按钮与厚重卡片样式，沿用当前明暗主题。手机保留小型关闭图标，节点不再弹出含内部 ID 的浏览器原生提示。

厂商浮层按可视窗口定位：下方不足时翻到上方，并夹在视窗边界内；滚动、缩放和尺寸变化后重算，节点离开视窗时关闭。切换节点或栏目时释放旧监听。图谱节点线宽为细线并采用 non-scaling-stroke，中心节点不以粗边框强调；外框使用细线。

### 一件事的研究流程（2026-09-07）

每个节点的第一问带研究面板（2026-09-28，研究页退役后）：这个节点及其骨架下级的研究问题（挂节点与变量类）、候选证据 / 陈述 / 回答、一跳关系，来自 `/api/research-summary?node=`，服务端按骨架过滤；公开只读看不到，页面如实说"登录后可见"。不把对象背景当成核实结论，不把任务总数声称为待办数。切换明暗不改变对象、视角、任务状态与证据。

本次替代“所有 folk 面板间距归零、所有线条统一深色”的实现；共用外框、控件、分隔线三个角色。图形、3D 和证据语义保持原约定。

### 3D 输入、材质与连续状态（2026-09-13 更新）

### 场景必需定义加载与恢复（2026-09-14 更新）

### 视觉模型的统一加载与替换（2026-09-14）

### 可见区域与镜头所有权（2026-09-14）

scene-view 是园区、机柜、比较台和部件查看器的共享视口/适配实现。画布以实际 CSS 尺寸设置相机比例和渲染缓冲，仅尺寸改变时重设；主场景画布避开页面明确提供的固定导航。页面明确主体集合：园区以建筑/设备聚焦，land 底板保留拾取与研究档案但作为场地背景；机柜包含全部研究网格。主体与当前已采用模型提供世界坐标边界，灯光、标签及不可见祖先不扩张边界。相机距离按包围球与较窄的视场角计算，旋转预览仍完整；空/非有限边界不能移动相机。雾化范围随适配视距更新，不允许正确投影的模型被旧雾区完全遮没。

比较台和部件查看器按旋转前、居中后的边界适配；重开清除上次 pivot 变换，查看器不使用固定 604/380 相机比例。关闭停止预览，页面退出断开尺寸观察和释放自己的 renderer/克隆材质，不释放借用几何。验收检查真实几何投影、导航、桌面/窄屏、旋转/重开、失败和版本替换后的镜头所有权；截图仍需审阅。浮动面板的全面避让、领域镜头艺术效果、HDR/纹理及长期 GPU 性能继续单列，不由 fit 推断完成。
