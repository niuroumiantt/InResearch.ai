## 管理后台运行 dashboard（2026-10-07）

`ops.html` 名称为「管理后台」，以自动读取的状态、进度、阻塞和下一步动作作为首屏，替代必须点击任务按钮才能看到原始日志的控制台。分区顺序：健康摘要与指标 → 需要注意 / 服务新鲜度 → 阶段进展 → 排队、执行中、阻塞任务定位 → 研究交付与事实/核验待办 → 可执行操作 → 手动执行记录与完整日志。账户、手动录价和生成物版本表折叠保留；沿用全站明暗主题、字体与导航，窄屏长表只在局部滚动。

- 首屏启动不等待字体样式或折叠表单的读取；首次状态读取后只复用已有字体缓存，无缓存时使用系统回退；不下载字库，状态请求优先，确保后续刷新不与字体争用连接；账户表、价格补全和生成物版本表仅展开后读取，失败可独立重试。管理状态响应只包含指标、聚合与有限诊断样本，不携带日报、匹配和交付明细；浏览器接受时压缩传输，20 秒超时给出中文错误并恢复刷新按钮。
- `/api/ops` 与 `/api/ops/log?id=<运行身份>` 仅管理员读取。状态查询不自动运行采集、阅读、核验清单或修改数据；每 30 秒刷新，恢复可见时重读。网站接收时间与 Spark 生成时间分别显示，任一未知或超过 15 分钟就不能报实时；新闻最近成功超过 45 分钟单列延迟。所有展示时间标北京时间 UTC+8，日志检索命令明确 UTC。
- 完整阅读文档、摘要阅读、分块任务成功、回执与研究采用分开计量。阶段和队列选取每份文档当前执行 revision（在途替代版本优先），不拿历史失败当当前阻塞；当前结果另用 `current_readings`。近 1h / 24h 计时间窗内所有版本的已结束任务，明示单位。点名批次和全库分别展示。
- 阻塞按执行异常、材料缺口、策略暂存分类；同一文档跨类以服务 / 执行 / 材料 / 策略优先归一计数。派生文件暂存、零分暂存、未支持格式、图纸/OCR 工作流缺口不自动归咎程序。展示错误码、最早当前受阻时间、文档/revision/job 身份与阶段代码入口；代码入口不是已经确认的异常行。长任务与无近期产出只提示核对，不自动重试或更换模型。
- Spark 快照每个状态发布最早 100 个任务样本、总数与上限，筛选仅作用于样本，空样本匹配不冒充全库无任务；全部错误组汇总用于分类，每组附最早 3 个定位样本，点击某错误时可定位到超出全队最早100项的该类任务；页面优先显示执行异常前五类。缺少新诊断字段、快照不可用、分区台账失败与实际零值分开显示；刷新失败保留旧画面并明确当前未确认，不留绿色健康结论。事实校验复用 `fact_contract.check_fact`，核验待办复用 `verify.build_queue`，读取无写入或采用权。
- 操作按查看状态、检查/清单、执行操作分组，写清实际影响。执行成功只表示该程序退出码为零，不代表待办完成、研究采用或整体正常；旧任务日志没有结果元数据，标未知。每次新手动任务保存开始/结束 UTC、耗时、退出码和结果；超时保留部分输出。预览保留开头摘要和结尾，完整日志按运行身份留存并下载；最近 50 次历史明确范围，不冒充常驻服务历史。成果按钮与实际 Markdown/JSON 输出一致，地图 PDF 条件明确。

验收：`tests/unit/test_operations.py` 覆盖只读查询、当前/历史版本隔离、文档与任务分母、样本上限、元数据未知、完整日志/超时记录和权限；`tests/ops_dashboard.cjs` 覆盖自动加载不执行任务、定位/筛选、错误与外部文本转义、刷新失败恢复、旧快照、窄屏与明暗。真实服务可用性、原件处理决策、历史日志全量覆盖和具体代码异常行需要实际服务日志核对。

### 3D 输入、材质与连续状态（2026-09-13 更新）

园区与机柜的主场景使用 `scene-picking.js`：仅主画布拥有拾取手势，坐标按实际画布边界计算；HUD、档案与其他画布不穿透点选，拖动不作为单击。不可见祖先下的网格不可选。高亮使用可清理的独立覆盖网格，不改研究网格材质；园区领域淡化只持有该网格的临时克隆，退出恢复原引用并释放克隆。热图与领域模式保持互斥，不以缓存的临时样式替代原材质。部件查看器通过 `materialFor` 接收场景提供的原材质并独立克隆，不再读取旧 `userData.orig` 协议，也不把热图或淡化材质当成原件。

`scene-motion.js` 为每项连续状态提供单一时间线。播放、领域目标和手动阶段共享滑杆所有权；后一次操作取消前一次，迟到帧不得写回。相机拥有另一条时间线，主场景拖动取消飞行。减弱动态效果直接抵达目标。页面继续拥有几何、阶段和相机目标配置；renderer/HDR/面板纹理和下钻加载的重复仍未完成拆分，GLB 模型按下节共享；必需定义加载按下节统一恢复。

### 场景必需定义加载与恢复（2026-09-14 更新）

两张 3D 页面通过 scene-data.loadSceneData 声明启动所需 URL 与集合字段；全部 HTTP/JSON/集合结构有效后才建立索引和 renderer。有效空集合可以保留；缺失或错误响应不能填成空集合。BOM、公司、模块、产品仍读发布定义，价格及指标仍读现行运行权威或投影，不新建数据副本。

加载期间只将页面明确提供的场景控制设为 inert，导航保持可用；失败面板符合共享外观、明暗与窄屏，用户可重试。默认 12 秒超时，任何失败或超时都取消当批其他请求；重试按新批执行，重复点击只开启一次。旧批迟到不会发布数据或覆盖当前状态；成功移除面板并恢复控件此前的 inert 值，renderer 只在成功返回后创建一次。该状态仅证明必需定义就绪，不包括 HDR/GLB/纹理和下钻资产；这些加载生命周期与真实 GPU 性能仍须另验。


### 视觉模型的统一加载与替换（2026-09-14）

两场景和比较台共用 model-assets.js 的 GLB 请求、内容 SHA 校验、解析与独占资源释放。可恢复加载槽持请求代次与超时；重试不并发重复，取消后迟到的解析只能释放结果，不能写回。新请求失败保留旧成功值。两场景先载入全部已采用模型，再一次替换显示组和 hideRack；部分失败不隐藏程序化几何，也不把半批成功当成完整版本。撤下采用后的空批移除旧组并恢复原可见状态。

几何、材质、纹理及 ImageBitmap 的释放限定在同次解析拥有的资源，同组共享资源只释放一次；不触碰主场景和研究查看器持有的对象。错误状态在共享外观、明暗和窄屏均可见，导航、相机及程序化场景仍可操作。比较台启动声明登记 schemaVersion=1，HTTP/版本不符复用 scene-data 的加载/重试入口，不能将失败解释为空登记；实际为空时保留明确提示。它展示采用身份与署名，网格结构仅作待核对线索，模型名字按文本渲染。

此约定覆盖 GLB 加载生命周期，尚不证明 renderer 初始化、HDR/面板纹理恢复、全部触摸设备、全部构图细节或长期 GPU 帧率达标。


### 可见区域与镜头所有权（2026-09-14）

scene-view 是园区、机柜、比较台和部件查看器的共享视口/适配实现。画布以实际 CSS 尺寸设置相机比例和渲染缓冲，仅尺寸改变时重设；主场景画布避开页面明确提供的固定导航。页面明确主体集合：园区以建筑/设备聚焦，land 底板保留拾取与研究档案但作为场地背景；机柜包含全部研究网格。主体与当前已采用模型提供世界坐标边界，灯光、标签及不可见祖先不扩张边界。相机距离按包围球与较窄的视场角计算，旋转预览仍完整；空/非有限边界不能移动相机。雾化范围随适配视距更新，不允许正确投影的模型被旧雾区完全遮没。

初次自动适配和显式“适配视图”可跟随画布大小；用户手势或领域镜头一旦接管，resize 和迟到的可选模型不能夺回镜头。显式适配取消旧飞行动画；页面继续提供领域镜头与阶段，不把业务目标放入通用 fit。主场景只读 model-assets 的当前 objects，查询返回独立数组且不取得资源释放权；失败保持旧组，版本退出后不再参与后续适配。阶段展开后用户可显式适配当前布局。

比较台和部件查看器按旋转前、居中后的边界适配；重开清除上次 pivot 变换，查看器不使用固定 604/380 相机比例。关闭停止预览，页面退出断开尺寸观察和释放自己的 renderer/克隆材质，不释放借用几何。验收检查真实几何投影、导航、桌面/窄屏、旋转/重开、失败和版本替换后的镜头所有权；截图仍需审阅。浮动面板的全面避让、领域镜头艺术效果、HDR/纹理及长期 GPU 性能继续单列，不由 fit 推断完成。
