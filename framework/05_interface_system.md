## 一套业务，两种视觉风格

用户在全站顶部选择 Attio 或 folk，实际页面立即切换。两个名称表示本项目依据参考设计实现的视觉方案，不是加载第三方官方皮肤或远程应用。

跨项目研究与基础变量由 [infra/design/crm](https://github.com/niuroumiantt/infra/tree/main/design/crm) 维护；本文件是本项目集成与验收的现行入口。基础变量按版本嵌入 `web/themes/site-skin.css`，不是跨站远程加载。

| 项目 | Attio | folk |
|---|---|---|
| 标题 / 正文 / 辅助 | 三层中性色，小圆角紧凑数据表 | 三层暖墨色，直角内容块，较舒展标题 |
| 外框 / 内行 | 淡灰外框、更淡行分隔 | 细深色外框、弱色内行；地图另用弱轮廓 |
| 面板 / 输入 / 操作 | 8px / 6px / 6px | 0 / 2px / 胶囊；面板间保留 18px 间距 |
| 导航与组织 | 蓝色操作与淡蓝选中 | 单色操作、文字选项卡细底线，不把所有导航做成胶囊 |

两套设计均使用自托管 Inter 与系统中文字体，不复制第三方专有字体。深色是本项目适配。参数不声称来自官方内部设计规范。

图标为本项目自有 SVG，同一语义对应两种几何表达。分类、排序、证据、任务状态及权限不随皮肤变化。功能复杂度仍由业务决定，不以参考网站的宣传插画替代真实内容。

## 风格与明暗分开

顶部统一显示 inresearch.ai；一级导航为总览、研究、资料、任务、成果，管理入口按角色出现。实习生只显示其可访问的任务入口；认证页只显示品牌与外观。各页面保留与当前内容相关的局部视图和操作，不再各自维护一级导航。

右侧将 Attio / folk 分段按钮与“外观”下拉框放在同一组；窄屏可整组换行并保持靠右，一级导航单行横向滚动。顶部实际高度由共享组件测量，页面和 3D 控件使用同一个偏移量。

风格只有 Attio / folk；明暗单独选择浅色 / 深色 / 跟随系统。默认 folk + 浅色，以用户提供的线条式参考为起点。只有选择“跟随系统”才响应操作系统明暗变化。

统一令牌位于 `web/themes/site-skin.css`，全部应用页使用同一文件；旧 CSS 变量只作为兼容别名，不再各自定义色板。颜色、边界、圆角、字重、间距组合、图标族均参与切换。不得在单页重新添加 `prefers-color-scheme` 色板或全局强制圆角规则。

偏好存于当前浏览器同源 localStorage（`inresearch.ui.v1`），跨页面、刷新及同源标签页生效；不跨设备同步，不写入研究数据或账号权限。存储不可用时本页仍可切换，并提示偏好未保存。脚本在首次绘制前设置根节点属性，降低错误色系闪现。

## 页面与 3D 范围

[界面清单](interface_manifest.json)列出全部应用页面和明确例外：16 个交互页面以及登录、改密、无权限页面接入共享外观。海报/打印交付物、开发烘焙工具、未采用提案原件保留各自用途；打印报告隐藏换肤栏并使用浅色纸张样式。

园区与机柜 3D 的控件、背景及雾色随外观变化。模型材质、覆盖率颜色、物理语义、相机和选中对象保留，避免视觉偏好改变研究含义。切换不重载页面，不重建业务数据。

两交互场景的 HDR、PMREM target 与 CanvasTexture 由 `scene-resources.js` 统一持有。页面只声明环境配方和纹理绘制内容；失败或超时保留程序化视觉，旧加载不能在重试或退出后夺回环境。替换释放旧 target，pagehide 停止渲染并释放环境、纹理池、composer 和 renderer。离线 bake 工具与比较台的短生命周期另行保留，不冒充已迁移。

登录前仅公开不含业务数据的外观 CSS、JS、Inter 字体与许可。所有研究数据、其他静态文件和 API 保持原权限边界。

## 新页面与验收

### 数据中心成本计算（2026-09-14）

`cost.html` 是研究层的独立交互页面，读取仓库内版本化的 `data/datacenter_cost_model.json`，按同一公式把资源、设施、设备、任务和资本回收五个边界对齐。页面必须明确区分全项目成本与设施侧观察账户；设施运维分摊若已包含在其他运营支出中，不得重复加入总成本。参数必须标识为研究假设，不得表现为报价、投资建议或跨硬件任务的等效算力结论。

网页基准必须与归档 Excel 对齐；交互修改只存在于浏览器当前状态，不改写研究权威。测试至少核对基准年化成本、单位成本、用电、用水、输入重算、恢复基准及窄屏边界。研究正文、来源笔记和工作簿保存在 `docs/research/2026-09-14/datacenter-cost/`，渠道发布版不作为页面计算权威。

新增 HTML 必须在界面清单登记为应用页或写明排除原因；应用页在 head 同步加载共享 JS，并在本页结构样式之后加载共享 CSS。页面负责布局与业务，共享外观负责视觉规则。

验收包括两种皮肤与明暗组合、移动宽度、键盘焦点、偏好保存及跨页/跨标签同步、研究节点与筛选状态保留、3D 背景切换、登录前资源边界及打印隐藏。`node tests/run_browser.cjs` 启动隔离本地服务并执行全套浏览器回归，CI 安装固定版本 Playwright/Chromium 后运行同一入口；本机可设 `UI_BROWSER_CHANNEL=chrome`。检查实际内容、按钮对比、组件圆角及整页溢出，不能只检查换肤按钮。

对象研究图谱按 [07 产品生态](07_product_ecosystems.md) 的中心切换、关系语义和导出约定实现。图形沿用当前皮肤的颜色与圆角，切换风格无需刷新；最终 SVG 解析并保存当时的样式，不依赖网站 CSS。

### 厂商浮层（2026-09-06 更新）

产品图谱的厂商浮层采用细线边框、无阴影、无大标题的纵向名字列表；每行一个厂商，使用普通文字与细分隔线。替代此前胶囊按钮与厚重卡片样式，沿用当前明暗主题。手机保留小型关闭图标，节点不再弹出含内部 ID 的浏览器原生提示。

厂商浮层按可视窗口定位：下方不足时翻到上方，并夹在视窗边界内；滚动、缩放和尺寸变化后重算，节点离开视窗时关闭。切换节点或栏目时释放旧监听。图谱节点线宽为细线并采用 non-scaling-stroke，中心节点不以粗边框强调；外框使用细线。

### 一件事的研究流程（2026-09-07）

保留当前对象与五种视角，详情增加“已知什么 / 此前做了什么 / 现在做哪一步”：陈述与回答、材料与证据、任务或研究问题分别进入原有记录视图。不把对象背景当成核实结论，不把任务总数声称为待办数。切换风格不改变对象、视角、任务状态与证据。

本次替代“所有 folk 面板间距归零、所有线条统一深色”的实现；共用外框、控件、分隔线三个角色。图形、3D 和证据语义保持原约定。

手机端研究概览、对象选择和团队模块概览默认收起，显式入口可随时展开；团队工单表按记录重排，派工操作保持完整文字。

从指定对象进入研究页时，桌面也收起全局介绍，保留可展开入口。3D 场景控制在手机上使用可收起底部面板；减弱动态偏好关闭自动旋转。长表格在可聚焦的局部容器滚动，不能撑宽整页。原文长链接允许换行；公司历史新闻显示实际扫描窗口，不标作近期信号。

文档和报告使用同一安全行内 Markdown 子集：原文先分词再渲染，代码段不转链接，链接仅允许 HTTP(S)。文档目录标题按文本显示，不能把渲染后的标题文本再次解释成 HTML。

CI 的 3D 外观矩阵与场景契约验收使用减少动态效果及 0.5 设备像素比，保持 360/1440 CSS 宽度和真实场景，避免无 GPU runner 被持续光栅化占满；本机截图用原像素比。该矩阵验证界面与交互，不替代 3D 渲染质量或帧率验收。浏览器作业最长 15 分钟，每套子进程最多 5 分钟；场景契约分步输出加载、研究就绪及所有权检查，超时不能记为通过。

## 2026-09-13：源码职责与共享结构

应用页通过 `<inresearch-shell data-section="…">` 显式声明导航归属，响应式面板声明 `data-responsive-panel`。shell 不再猜 URL 分类、扫描旧导航补图标或包裹任意 hud。`web/themes/preference.js` 只维护偏好与外观事件，`web/components/site-shell.js` 拥有导航与控件。认证页使用同一布局、样式和表单错误/重试流程，账号模块不再携带 HTML。园区与机柜共用部件查看器和价格序列摘要，查看器自己管理画布和克隆材质，不释放主场景几何。公开 URL 由 `web/routes.json` 对应唯一源码，不复制旧实现。


### 3D 输入、材质与连续状态（2026-09-13 更新）

园区与机柜的主场景使用 `scene-picking.js`：仅主画布拥有拾取手势，坐标按实际画布边界计算；HUD、档案与其他画布不穿透点选，拖动不作为单击。不可见祖先下的网格不可选。高亮使用可清理的独立覆盖网格，不改研究网格材质；园区领域淡化只持有该网格的临时克隆，退出恢复原引用并释放克隆。热图与领域模式保持互斥，不以缓存的临时样式替代原材质。部件查看器通过 `materialFor` 接收场景提供的原材质并独立克隆，不再读取旧 `userData.orig` 协议，也不把热图或淡化材质当成原件。

`scene-motion.js` 为每项连续状态提供单一时间线。播放、领域目标和手动阶段共享滑杆所有权；后一次操作取消前一次，迟到帧不得写回。相机拥有另一条时间线，主场景拖动取消飞行。减弱动态效果直接抵达目标。页面继续拥有几何、阶段和相机目标配置；renderer/HDR/面板纹理和下钻加载的重复仍未完成拆分，GLB 模型按下节共享；必需定义加载按下节统一恢复。


### 3D 研究关联摘要与就绪验收（2026-09-13 更新）

部件档案通过 `/api/research-summary` 读取问题、证据、任务与邻接所需的身份引用。完整工作台继续使用 `/api/research` 读取正文、材料和产品目录；两者共用研究状态组装与同一个 `buildResearchIndex.forNode` 关联算法。摘要未携带的材料字段不能解释为没有原文，不按公司或目录数量推定证据。Reader 不可用或延迟时保留对应提示。

完整视图与摘要的请求缓存分开，旧失败不得清空新请求；每次挂载有独立身份，A→B→A 的旧成功或旧失败都不得写回。未载入、找不到对象和加载失败分别显示，失败可重试。3D 验收必须等研究面板 ready 并检查实际计数及邻接，不以档案标题或旋转画布出现代表研究内容已就绪。全量对象关联一致性与请求生命周期在 `tests/research_summary.cjs`；真实两场景内容验收在 `tests/part_dossier.cjs`。


### 场景必需定义加载与恢复（2026-09-14 更新）

两张 3D 页面通过 scene-data.loadSceneData 声明启动所需 URL 与集合字段；全部 HTTP/JSON/集合结构有效后才建立索引和 renderer。有效空集合可以保留；缺失或错误响应不能填成空集合。BOM、公司、模块、产品仍读发布定义，价格及指标仍读现行运行权威或投影，不新建数据副本。

加载期间只将页面明确提供的场景控制设为 inert，导航保持可用；失败面板符合 Attio/folk、明暗与窄屏，用户可重试。默认 12 秒超时，任何失败或超时都取消当批其他请求；重试按新批执行，重复点击只开启一次。旧批迟到不会发布数据或覆盖当前状态；成功移除面板并恢复控件此前的 inert 值，renderer 只在成功返回后创建一次。该状态仅证明必需定义就绪，不包括 HDR/GLB/纹理和下钻资产；这些加载生命周期与真实 GPU 性能仍须另验。


### 视觉模型的统一加载与替换（2026-09-14）

两场景和比较台共用 model-assets.js 的 GLB 请求、内容 SHA 校验、解析与独占资源释放。可恢复加载槽持请求代次与超时；重试不并发重复，取消后迟到的解析只能释放结果，不能写回。新请求失败保留旧成功值。两场景先载入全部已采用模型，再一次替换显示组和 hideRack；部分失败不隐藏程序化几何，也不把半批成功当成完整版本。撤下采用后的空批移除旧组并恢复原可见状态。

几何、材质、纹理及 ImageBitmap 的释放限定在同次解析拥有的资源，同组共享资源只释放一次；不触碰主场景和研究查看器持有的对象。错误状态在 Attio/folk、明暗和窄屏均可见，导航、相机及程序化场景仍可操作。比较台启动声明登记 schemaVersion=1，HTTP/版本不符复用 scene-data 的加载/重试入口，不能将失败解释为空登记；实际为空时保留明确提示。它展示采用身份与署名，网格结构仅作待核对线索，模型名字按文本渲染。

此约定覆盖 GLB 加载生命周期，尚不证明 renderer 初始化、HDR/面板纹理恢复、全部触摸设备、全部构图细节或长期 GPU 帧率达标。


### 可见区域与镜头所有权（2026-09-14）

scene-view 是园区、机柜、比较台和部件查看器的共享视口/适配实现。画布以实际 CSS 尺寸设置相机比例和渲染缓冲，仅尺寸改变时重设；主场景画布避开页面明确提供的固定导航。页面明确主体集合：园区以建筑/设备聚焦，land 底板保留拾取与研究档案但作为场地背景；机柜包含全部研究网格。主体与当前已采用模型提供世界坐标边界，灯光、标签及不可见祖先不扩张边界。相机距离按包围球与较窄的视场角计算，旋转预览仍完整；空/非有限边界不能移动相机。雾化范围随适配视距更新，不允许正确投影的模型被旧雾区完全遮没。

初次自动适配和显式“适配视图”可跟随画布大小；用户手势或领域镜头一旦接管，resize 和迟到的可选模型不能夺回镜头。显式适配取消旧飞行动画；页面继续提供领域镜头与阶段，不把业务目标放入通用 fit。主场景只读 model-assets 的当前 objects，查询返回独立数组且不取得资源释放权；失败保持旧组，版本退出后不再参与后续适配。阶段展开后用户可显式适配当前布局。

比较台和部件查看器按旋转前、居中后的边界适配；重开清除上次 pivot 变换，查看器不使用固定 604/380 相机比例。关闭停止预览，页面退出断开尺寸观察和释放自己的 renderer/克隆材质，不释放借用几何。验收检查真实几何投影、导航、桌面/窄屏、旋转/重开、失败和版本替换后的镜头所有权；截图仍需审阅。浮动面板的全面避让、领域镜头艺术效果、HDR/纹理及长期 GPU 性能继续单列，不由 fit 推断完成。
