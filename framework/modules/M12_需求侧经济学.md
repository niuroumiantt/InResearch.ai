# M12 需求侧经济学（Token 经济）

## 定位与边界
回答"AI 应用端赚不赚得回来"——200GW 叙事成立与否的最终检验。覆盖 token 价格曲线、
推理单位成本、AI 公司收入/ARR、企业渗透率、单位算力收入 vs 单位算力成本。
**这是判断周期顶部最领先的模块**，领先物理层空置率 12–18 个月。合同事实归 M03。

## 核心问题
1. 每百万 token 价格（旗舰/中档/开源自托管）的下降曲线与降幅节奏？
2. 推理单位成本（$/M token）的硬件+能耗分解，毛利空间还有多厚？
3. 头部 AI 公司（OpenAI/Anthropic 等）收入增速 vs 算力承诺支出的比值走势？
4. 企业 AI 支出的真实渗透率与续约率（不是试点，是生产负载）？
5. "单位算力收入 / 单位算力全成本"比值：>1 的负载占比在扩大还是缩小？
6. Agent/长推理负载对 token 消耗量的乘数效应有多大（量能否补价）？

## 关键指标
- `token_price_flagship`：旗舰模型 API 价格（月度）
- `ai_revenue_capex_ratio`：头部 AI 公司收入 / 算力支出承诺（季度）
- `inference_unit_margin`：推理毛利估算（季度，转负触红）

## 数据依赖
`prices`（token 价格、GPU 租价）；`companies`（AI 公司收入披露）。

## 更新节奏与输出
月度跟踪价格；季度输出"需求经济学温度计"——M15 情景切换的第一触发器。
