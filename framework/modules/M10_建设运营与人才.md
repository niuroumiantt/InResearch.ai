# M10 建设运营与人才

## 定位与边界
回答"有没有人把它建出来、运营起来"。覆盖总包（GC）产能、机电分包、电气技工短缺、
建设周期变化、O&M 市场、运维人才。设备交期归 M09；本模块管"人和工程执行"。

## 核心问题
1. 头部数据中心总包（Turner/DPR/Holder 等）的产能与在手订单？
2. 电气技工/焊工缺口的量化证据（工资溢价、招聘周期）？
3. 从开工到通电的实际建设周期走势（拉长即执行瓶颈显性化）？
4. 预制化/模块化建造的渗透率与对周期的压缩效果？
5. O&M 外包市场格局与单 MW 运维成本？

## 关键指标
- `construction_duration_months`：L6→L8 实际周期中位数（半年，从项目库直接算）
- `electrician_wage_premium`：数据中心电工工资溢价（半年）

## 数据依赖
`projects`（状态时间戳推算周期）；`companies`（总包/分包档案）；`prices`（人工成本）。

## 更新节奏与输出
季度刷新；输出执行瓶颈评估（供 M15）。
