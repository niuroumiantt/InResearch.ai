# 文献阅读、评分与采用标准 v4

> CURRENT · 2026-10-07。规则归属与替代关系见 framework/CURRENT.md。

> 2026-09-06 用户采用生效。依据：[研究架构 v2](../docs/reviews/2026-09-06/RESEARCH_ARCHITECTURE_V2.md)；常驻执行见 [RUN_TO_COMPLETION](../docs/local_reader/RUN_TO_COMPLETION.md)。本标准替代 v2 的低分过滤、凭摘要判 depth、分数驱动物理改名与“精读即可直接引用”规则。现行口径和 C3 采用门槛不变。

v4 按 2026-09-12 用户方向补充可配置模型和单一有效阅读结果；保留 v3 的原件与 C3 边界。2026-09-26 用户采用按分数分层阅读深度（§1），替代“所有独立文章都全文深读”。

## 1. 按分数分层阅读深度

原件登记 → 完整性检查 → 配置的研究模型粗读 → 按有效优先级决定深度 → 阅读质量检查 → 分类与证据候选 → 原文核验 → 既有 C3 研究采用。

有效优先级取粗读前已有的优先级（M4 L1、apply-triage、点名、现行需求匹配）与本次粗读 importance 的较高者，粗读不降低已有判断。深度分三档（2026-09-26 用户采用）：

| 有效优先级 | 深度 | 终态 |
|---|---|---|
| ≥ `READER_FULL_READ_MIN_PRIORITY`（默认 7），或点名 | 全文深读：逐块阅读、综合、封印报告 | 深读完成（complete） |
| 1–6 | 摘要深度：只读首、中、尾三块，保留块结果与粗读，不生成全文报告、不成为当前全文结果 | 摘要（summarized） |
| L1 为 0 分，或确认是 reader 衍生物回流 | 不读：`reader park` 停放，保留原件、台账与 L1 结论 | 停放（blocked，`parked_*`） |

块数不超过三块的文档直接全文深读。摘要可用 `reader deepen` 继续到全文，已读块不重读；停放可用 `reader retry --error-code parked_…` 恢复。摘要与停放都不计入全文深读完成。粗读不按年份、机构或目录抽样剔除文章；旧积压保留服务份额并随等待时间提权。持续新增按接收批次/截止日统计，不承诺永久“全库 100%”。

完全相同内容哈希且满足相同阅读标准的结果可继承，记录依据；同名/相似标题、译本与新版不能当重复。工程图纸、3D、数据集、依赖包采用类型对应的完整普查与处理契约，不冒充文章已读。损坏、加密及实际文字提取不完整进入异常/补读；默认正文模式的图片排除与空文字层页另记范围，不冒充完整视觉深读。

模型接入、配置和单一有效阅读结果按 [08 模型执行](08_model_execution.md)；当前暂用 Claude CLI，Spark 恢复后通过配置接入，型号不属于阅读资格或采用规则。换默认模型不自动重读已有材料。

### 2026-10-06：阅读服务于现行骨架的需求

新建阅读版本冻结现行节点/问题、目标表 SHA 与材料命中的目标行。目标行保留五类变量、六队归属、模型输入与主输入，阅读提示据此回答成本/收入/回报、四问和具体证据缺口。页内匹配仅是检索候选；模型必须核对每项主张的原文、范围、时点、单位、条件与反证，不能把匹配当采用。

用户材料命中 needed/assumed/delivered 的现行需求时，新建阅读版本优先级至少为 7；其中有模型主输入时为 8。只是安排全文阅读，不提高来源等级、不修改目标状态或模型值。未命中材料不因上传扩大队列；已登记的历史版本、配方、产物和停放决定保持，换提示不触发全库重读。同 SHA 再交付命中需求、且旧版本仍 queued/extract 或 queued/triage 时，只提升阅读优先级并留目标 SHA/前值审计，不改冻结配方；已在读/已完读/停放不自动变动。

2026-10-06 分流调度：每四次派工分别服务最老合格任务、已有可执行综合/整理/回执的收尾任务、来源明确的短日报 HTML、通常优先级任务。收尾槽为空时也可服务日报；没有对应任务时回退普通排序。日报资格来自实际 daily-receive 回执及绑定来源，按剩余块数优先，未提取的日报随后处理。所有槽遵守 claim floor、失败重试/available、冻结配方和完整覆盖；不提高 importance/C3 分数，不额外启动模型 worker，不打断已运行任务，也不取消温度保护。last_dispatch 记录实际通道和任务。补源、项目身份和容量采用另行分流，不作为整批阅读的前置锁。

新版本以一棵树的节点分类，问题记录附带 node 与 variable_class；M01–M15 仅为旧版本的兼容属性，不再要求新模型用其决定分类。新全文结果的 library 主链接在 `library/by-node/<节点>/`；接收阶段的多节点候选入口在 `library/candidates-by-node/<节点>/variable-N/`，两个入口均回到 SHA 原件。旧链接不搬动，也不冒充新骨架的采用结果。新角度按现有节点/变量类提出待讨论建议，骨架变更继续由用户讨论决定。

### 2026-10-06：用户点名整批与远程推理

用户显式要求整批阅读时，用运行配置 `READER_DOCUMENT_SCOPE` 的 JSON 定义 doc_ids 与是否包含已验收后续日报；范围内未命中需求的文章也登记并全文阅读，未匹配角度保持提案。该范围只控制注册/领取，不提高来源或采用等级；文件缺失/无效时停止，不能回退全库。范围内 floor=0、full_read_min_priority=1；各服务槽位均遵守范围。旧资料库任务与完成结果保持，不因本批迁移全库重读。

未产出首次全文结果的旧模型任务可用 `restart-unfinished`，固定旧 execution revision、请求键、原因与新模型身份；取消旧未运行任务但保留尝试/块/原件，事务新建配方及执行入口。重复键回放，迟到基线拒绝，正在执行或已有完整结果拒绝。新版本完整机检后按首次候选交付；此入口不能替换已完成结果。已有结果仍用 §8 的独立重读与审阅。

模型额度耗尽等 `model_quota_wait` 暂停推理任务 900 秒，连接中断 `model_relay_unavailable` 暂停推理任务 60 秒；已产生完整整理产物的 `receipt` 不调用模型，等待期间仍可在原 scope/floor/available 与封印校验下领取并封存。中继槽位占满单独记 `model_relay_busy`，仅该任务退避 10 秒，不暂停其他任务。以上等待均不消费任务尝试、不降低阅读优先级，状态披露实际原因。Spark 只在当地 GPU 推理时受温度保护；远程 Codex 推理不消耗当地 GPU，恢复本地 Ollama 时原温度保护继续生效。

### 2026-10-07：默认正文阅读，跳过图片 OCR（用户采用）

以后新材料默认直接提取并阅读可用文字层，不对混排图片做 OCR，也不以图片未读阻塞正文交付。用户选择以正文描述支撑当前研究；纯图片/扫描材料没有可用文字层时保留原件，标为 `image_only_requires_user_text`，由用户先处理后补充可读版本，不自动尝试 OCR。PDF、HTML、Office 原件仍长期保存在 Spark；TXT 与页码/哈希清单为派生副本，不另计为新原件或新的已读报告。

PDF 新配方冻结 `pdf_mode=native_text_only`。报告及网页明确标为“正文阅读 · 图片未读”，保存 `scope=pdf_native_text_only`、`visual_review_performed=false`、未读图片页和没有文字层的页号。`coverage.complete` 只证明本配方全部可提取文字已逐块处理；`native_text_pages_read` 记录实际有文字的页数，`full_document_complete=false`，空文字层页不认证为空白页。矢量图也跳过，图片页清单不保证枚举所有矢量图。只使用正文中连续逐字引文产出候选，图片不能被猜成证据，正文未提供的参数标未知；正式采用仍按 01 的口径与 C3 核验。

已有冻结的视觉配方和已完成结果保留，不能因切换默认值修改旧产物。当前点名批次未完成 PDF 通过 `restart-unfinished` 显式创建正文版本并保留旧 OCR 尝试；未来新登记采用默认正文配方。`full_visual` 仅作为明确选择的兼容模式保留，其视觉双读/缺页限制继续适用；普通流程不自动启用。恢复视觉模式须冻结新的阅读版本，不覆盖原件、证据和已完成报告。

### 有界合批阅读（2026-10-07）

用户授权优化吞吐。新建 PDF 正文配方冻结 `read_batch`：版本 `read-batch-v1`，每次最多 4 个相邻块、合计最多 6000 字符；页内分块、原文 SHA、页码和每块结果保持独立。一次模型调用须返回每个块的结果，逐块核验 hash、允许 ID、摘要、主张和连续逐字引句；邻页的文字不能支持本页引文。精简重复表述不降低逐块全文覆盖、日期/口径/条件/反证和未匹配角度的记录要求。

认领在同一事务内，仅合并同一阅读版本的相邻、可执行任务；延迟、已认领或超字符预算的块不跨越。返回缺块、重复块、错 hash、超时或截断时回退原逐块契约；单块错引仍最多纠正一次，未核实主张按现行规则舍弃并计数。额度或连接等待释放本批认领，不消费尝试、不继续请求。完整报告和正式采用门槛不变。

旧冻结配方缺少 `read_batch` 时继续逐块执行，配置变化不改写旧结果。需要迁移的未读报告通过 `restart-unfinished` 建立新执行版本，原件、旧提取和尝试保留；已经开始正文阅读的材料先完成，不因提速重读。机器参数 `READER_READ_BATCH_CHUNKS`（1–4，1 禁用）、`READER_READ_BATCH_CHARS`（1–6000）仅影响新配方；推理并发与阅读块数分别计量，吞吐仍按整篇完成计算。

## 2. 深读的可检查产物

1. 按冻结范围覆盖正文、附录、脚注及可提取表格；默认正文模式跳过图片，兼容视觉模式另覆盖图形；保存章节/页块清单、每块处理结果及全文综合。长文分块后不得丢失前后条件或静默截断尾部。
2. 重新访问原文，不扩写粗读摘要。记录定义、作者主张、原理/方法、样本、假设、接口、适用条件、反例、局限和未知。
3. 可提取表格保留行列、单位、期间、实际/预测、注释；默认模式只使用正文中的图表描述，视觉模式另解释图形；阅读覆盖与理解质量分别核验。
4. 形成阅读报告、数字和非数字候选、与节点/问题/关系的关联，以及新问题/新分类提案。允许“深读无新增”，不凑数字和 Finding。
5. 保存文档/版本 ID、SHA-256、模型与配置、提取器/提示词/标准版本、执行时间、覆盖与质量记录；模型参数量或多轮一致不能证明深读质量。

## 3. 数字与非数字证据

数字候选记录 metric 候选、value/range/bound、unit、caliber、观察/发布/预测时点、来源及定位；指标不明先留候选，不编造 ID。原理、规范、结构关系、机制、事件、测试、预测和假设采用有身份与类型的 statement 候选，保留主体、条件、支持/反驳和证据；不能因数字密度低忽略标准与失败案例。

原件哈希、doc/version/source ID 与页/节/表/图/单元格共同定位；缓存键须经过来源映射，不能冒充 source_id。扫描表核对原页；原生表检查单元格、公式和表头。采用的关键数逐项核对负号、小数、倍率、单位、边界、跨页续表和脚注，重要表复算合计/比例。OCR 与原图不一致留异常，不猜。

模型生成的证据引文必须是该块原文中的连续逐字摘录，核验时仅忽略空白差异；不得翻译、转述、修补断词或拼接远处文本。无法确认逐字相符时，舍弃该主张，不以近似引文凑数。引文不符先带反馈重新生成一次；仍不符的主张从结果中剔除，连同原引文记入该块 `dropped_claims`，报告覆盖计入 `dropped_claims` 条数并写明警告；被剔除的主张不作证据、不进入报告主张。保留下来的引文必须全部逐字相符才能封存，报告的剔除条数与各块记录不一致不得封存（2026-09-27 起）。块摘要、综合摘要与要点不得是占位文字（整段只是“测试/示例/占位”标签，或以“测试摘要”“测试要点”开头）；出现时按模型输出无效（`model_output_placeholder`）重试，不得写入结果（2026-09-28 起）。

作者声称、厂商规范、实际测试、估算、预测及情景假设分开；两个模型抽取同一值不是两个独立行业来源。来源可追溯、口径相容、独立核验、C3 采用是不同检查，不能互相替代。现行事实推算限制与中外口径不因本标准放宽。

## 4. 阅读 depth、质量与采用分别记账

| 历史兼容 depth | 含义 | 当前处理 |
|---|---|---|
| 精读 | 有逐份原文阅读记录 | 需覆盖/质量证据；标签本身不等于采用许可 |
| 据实生成 | 原表逐行解析并定位 | 只说明局部提取，不豁免该独立文章全文深读 |
| 半自动 | 标题/片段/数字行等有限读取 | 全部进入深读队列，分数只排序 |
| 成员精读 | 成员已读，尚待质量审计 | 保存执行依据并审计，不直接进入核心事实 |
| 目录级 | 目录或机械索引 | 只用于发现文件，展开到独立文章安排深读 |

`depth` 必须来自实际执行与可回查记录，**禁止根据 summary、文件名、rescore、批次默认值或措辞推断，缺省不得标精读**。旧标签和评分保留为历史判断；缺执行依据另记待验证，不静默提级或豁免新标准。读取状态、质量状态、整理状态、候选核验和采用状态独立；登记 sources 或路径出现不能判定已读/已消化。

## 资料先交付，正式采用按用途核验（2026-10-08 替代）

已封存的正文主张与引句直接进入02定义的资料基座，按现有节点/问题展示。历史资料的基础使用不等待逐条行业核验、C3、独立抽样或Git发布；不为填充已有资料重新阅读原件或启动OCR。原始年代、范围和出处随条保留，评分8–9的资料同样可用。

下文C3、重要性和独立复核要求适用于把来源记载升级为正式结论、当前答案、模型参数或项目/合同/GW统计。尚未升级的资料照常供研究使用，核验失败只影响相应正式采用，不遮蔽其已有原文。新证据优先服务当前需求与真正需要更新的字段；历史知识不要求在展示前证明今天仍有效。

## 5. 评分用于优先级与采用分流

importance 1-9 和 confidence A-C 保留兼容历史及 C3。每次评分记录理由、依据、阅读阶段和标准版本；粗读为暂定，深读可修订且保留前值。

评价内容包括原理/教学价值、接口/标准、方法与可考性、实证与失败案例、缺口匹配、时效、独立核验和反面价值。付费、独占数字、每页数字密度、中文或跨模块关联不自动加分；不能把收费和机构名等同可信。A/B/C 来源特征继续区分一手/实测/规范、机构预测/会议、转述/方法不明，证据等级按具体主张判断，不由整篇分数代替。

| importance | 兼容解释 |
|---|---|
| 8-9 | 关键基础/重要实证或重大判断影响，按 C3 进入 A 档 |
| 5-7 | 有价值的方法、原理、案例、参数或补证，采用需满足 C3 条件 |
| 1-4 | 历史背景、重复信息或贡献有限；摘要深度阅读，保留块结果，可 deepen 到全文 |

采用按 [01 口径手册 §4](01_data_standards.md#4-来源冲突与证据采用) 的唯一 C3 定义执行；分流、存档、审阅与正式采用分别计量。DECISIONS 只记录变更，不作为另一份采用规则。

## 6. 身份、命名与目录

文档身份、内容版本与原文件 SHA-256 分开登记；原名、原路径、接收批次保留。规范显示名可用“年份_机构_标题__短ID”，缺失字段标未知。分数放元数据；旧带分数名称作为历史别名或导出名，不再随评分移动原件。

原件不改字节、不删除；library 为可重建多视角入口，同一文献可关联多节点，每条关联有具体证据范围；历史模块入口仅兼容旧链接。新词优先匹配别名、类型、型号、实例与条件；分类边界变化需有版本、理由、证据、影响和映射。

自动整理只执行规则验证通过的操作计划：合法分类、源哈希、目标冲突、旧新路径、操作日志与可恢复状态。文献中的文字不获得文件执行权限。包内相对路径与依赖保留；解压不删除原包；磁盘不足不能清原件腾空间。

## 7. 输出与专家能力

Spark 持续产出原文可回查的阅读成果和候选，研究侧按 C3 更新来源、facts、statements 与 Finding。覆盖按范围版本和节点×问题衡量，原理与数字同样可以回答问题。每篇有终态：深读完成、结果继承、摘要、停放、待补读/异常等；摘要、停放与异常都不计全文完成。所有被提取候选都有采用、待核、冲突、背景或无增量去向。

## 8. 显式重读与当前版本

内容 SHA 标识原件；阅读 revision_id 标识一次完整阅读及其冻结配方。每个内容身份只有一个当前阅读指针，待验收的新版本不进入当前导出。首次完整阅读仍自动产出候选，C3 采用资格不因此改变。

重读由 `reader reread` 显式提出，记录旧版本基线、稳定请求键和原因；读取原件，生成独立提取、逐块结果及报告。换默认模型不创建重读；`retry` 只重试原版本失败任务，配方不匹配仍须恢复原配置。不同模型、后端或更大参数规模不自动取得替换权。

新版本达到 ready 只说明原件哈希、配方、覆盖、块内容和报告通过机检。审阅者通过 `inspect-revision` 核对正文、尾段、引用与理解质量，再以报告 SHA、旧版本基线、审核人和理由执行 `activate-revision`。程序重新验证被审阅的产物，事务内比较旧指针并一次切换；重复请求不重复生效，迟到或被拒绝的版本不能覆盖当前结果。模型失败、损坏、不完整覆盖或提交失败保留旧结果。未通过语义核对时 `reject-revision` 关闭候选，记录和原件保留。

阅读验收是阅读结果选择，仍不等于 C3 采用。旧报告、被引用的旧证据和原件保留；新候选证据使用独立阅读版本 ID，不能借用旧证据身份。当前快照每个内容身份只投影一项，历史版本经台账和具体产物路径回查。原件 library 名称保留为接收时的别名，不随重读移动原件，也不成为当前阅读结论的权威。


## 9. 终端处理与共享全文结果

`reader current --sha 完整SHA` 与 `deep-read current --sha 完整SHA` 查询同一个 reader catalog；当前指针仍只有 documents.current_revision_id。共同的只读用例验证原件、覆盖、配方和产物封印，返回阅读版本、报告 SHA、报告原路径及候选身份。查询不运行模型、不初始化或升级库；旧库需要显式升级，缺失库、尚无当前结果和旧未验证报告分别说明。产物损坏报错，不用重新抽取来掩盖损坏。机检与已保存的审阅记录仍不证明全部语义正确。

L2 的 queue/record/skip 是事实处理任务，其回执不是全文阅读报告。旧 l2_read.jsonl 保留为历史处理台账；documents_processed、already_processed、eligible_unprocessed 与相似提示中的 processed 只反映事实处理。旧回执不自动导入为 reading_run，也不改变全文完成数。

L2 pack 有合格当前结果时，复用其已核对的页块正文和报告版本；每个任务包固定引用生成时看到的版本，之后切换当前结果不改写旧包。没有合格当前结果时仍可提供抽取输入，但不得称其为已完成全文阅读。pack --again 只是重新处理事实；正式全文重读与替换继续按第 8 节执行。

两个客户端须使用同一数据根：READER_DATA_ROOT，或分别使用 reader --data-root 与 deep-read --reader-data-root。未配置的跨机器副本不因此自动同步；真实旧资料须先清点、核对覆盖与身份后受控导入，不能凭人工回执编造完整产物。
