# 工单 BATCH01-C：数据中心 ABS presale 报告采集（M11 资本与金融）

你好。这是首批三张工单里最需要判断力的一张，交给你是希望你能啃硬骨头。
背景直说：M11（资本与金融）是我们 15 个研究模块里**最薄的一个**——只有 3 条研究结论，
却压着 24 张采集工单。而这个行业当前最大的问题恰恰是钱：谁在出钱、什么条款、杠杆多高。
你这单做好了，是给整个项目补上最短的那块板。

## 任务

采集 2024 年以来的**数据中心 ABS（资产证券化）与项目融资的 presale/新发行报告**。

去哪找（全部免费，注册即可）：

- **评级机构 presale 报告**：S&P Global Ratings、Moody's、KBRA、Fitch 官网，
  搜 "data center ABS presale" / "data center securitization"。
  这是公开材料里信息密度最高的一类——一份 presale 通常包含发行规模、期限、
  票息/利差、LTV、租约加权剩余年限、租户集中度、DSCR。
- 发行人线索（用来搜）：Aligned、Vantage、Switch、Compass、Stack、DataBank、
  Cologix、CyrusOne——这些是近年 ABS 常客。
- 辅助：Structured Finance 行业媒体的发行汇总报道（用于查漏，数据仍以 presale 原文为准）。

## 每笔交易提取什么

| 字段 | 说明 |
|---|---|
| 发行人 / 交易名 | 如 "Vantage Data Centers Issuer LLC 2025-1" |
| 发行时点 | 年-月 |
| 规模 | USD，照实记（对外发布时系统会自动转区间，你记录时给精确值） |
| 期限与预期到期 | 年 |
| 票息或利差 | 注明是固定票息还是对基准的 spread |
| 评级 | 各档评级 |
| 抵押资产 | 几个数据中心、总 MW（**只记报告披露的数，未披露不推算**） |
| 租户与租约 | 加权剩余年限、前三大租户占比（如披露） |
| 报告链接 | presale 原文 URL |

## 规矩

1. 数字**只从 presale 原文取**，媒体转述的数字仅用于定位交易，不直接入库。
2. 报告没披露的字段留空，不从别处拼凑——同一笔交易不同来源的数常常口径不同。
3. 每份 presale 报告本身也是好材料：PDF 存下来随投递一起交，走打分入库流程。

## 交付

- 目标：先把 2024–2026 的交易清单拉全（预计 15–30 笔），做成一张 CSV（一行一笔交易，
  列即上表字段）+ presale PDF 一起投递到 `docs/inbox/submissions/你的名字_日期/`。
- 先交清单（哪些交易、各自找到了什么材料），核对完覆盖面再逐笔填数——
  避免深挖了十笔才发现漏了半个市场。
