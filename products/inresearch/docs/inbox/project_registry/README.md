### 字段

| 字段 | 含义 |
|---|---|
| `project_id` | `CN-DC-001` 起顺编，按项目目录名排序 |
| `region` | 恒为 `CN` |
| `project_name` | 目录名去掉日期前缀后的原文，未做任何改写 |
| `owner` / `owner_type` | 业主主体与类型（运营商/广电/金融/电力/政府公共/互联网科技/制造业） |
| `owner_source` | **`explicit`=目录名写了全称；`inferred`=只写了「六安电信」这类简称，由简称推得；空=识别不出** |
| `year` / `month` | 目录名前缀的日期（多为设计或交付时点，非投产时点） |
| `province` / `city` | 从目录名解析；解析不出留空 |
| `area_hint` | 只能定位到大区（华南/南方等）时填这里，**不塞进 province** |
| `phase` | 期数（一期/二期/二阶段…） |
| `scale_hints` | **只抄目录名里出现的规模线索原文**（DC4、DC5、1#厂房、1号楼、通信枢纽楼…），未换算成任何数量指标 |
| `disciplines` | 该项目档案中出现的设计专业（电气/暖通/给排水/土建/结构/建筑/智能化/消防/机房工艺/总图/装修/幕墙/钢结构） |
| `n_files` / `n_drawing` / `n_pdf` / `n_office_readable` | 文件统计。`n_drawing` 为 dwg+dwf |
| `source_dir` | 相对主仓库根的目录路径 |
| `notes` | 识别不出的字段在此说明原因 |

### 口径提醒（合并进项目库前请读）

1. **本表不含机柜数、功率、面积、投资额、PUE——目录名里没有这些信息，
   本地会话未做任何推断。** 这些数字要么在图纸里（提不出文本），
   要么在可研/概算文档里（见下方「下一步」）。
2. `year` 是**目录名上的日期**，多数对应设计或图纸交付时点，
   不能当作投产年份使用。
3. **有两组重复/同源项目**，并入项目库时需去重或按期合并：
   - `2020.7 福建广电网络莆田NGB业务中心（机房）` 与
     `2020.7福建广电网络莆田NGB业务中心（机房）`（差一个空格，同一项目两个目录）；
   - `2021.1 六安电信…` 与 `2022.1 六安电信…`（同一项目的两个时点）。
4. `owner_source=inferred` 的 3 条（六安电信 ×2、重庆移动 ×1 等）请自行判断是否采信。
5. 未识别业主 11 条、未识别省市 6 条，均因目录名确实不含该信息
   （如「大数据应用工厂项目」「产业园大数据中心建设项目」），已在 `notes` 注明。
