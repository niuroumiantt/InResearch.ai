# Signal Desk UI：可复用设计指南

## 一句话定义

**编辑部的信息层级 + 工业操作台的状态语义 + 新粗野主义的硬边表达。**

它不是“科技感渐变页面”，而是一套为高密度信息、来源健康和处理结果服务的视觉系统。

## 设计 DNA

1. **纸张而非画布**：背景使用暖米白 `#F3F0E8`，降低长时间阅读的刺眼感。
2. **荧光色只表示信号**：酸绿 `#D7FF35` 只用于当前态、关键数字、时间线节点和通过门禁的内容。
3. **硬边网格**：零圆角、细边框、少阴影。结构靠线和网格，不靠漂浮卡片。
4. **双层字体**：超大、紧字距的无衬线标题负责叙事；微型等宽字体负责时间、状态、来源和系统标签。
5. **轮廓字是签名**：Hero 第二行使用描边字，形成 Signal Desk 最强的品牌记忆点。
6. **密集但不拥挤**：行高短、纵向间距小，但列宽、对齐和层级必须严格。
7. **颜色必须有业务语义**：绿色=正常，琥珀=观察，红色=失败/排除，灰色=TBD，蓝色=外部链接。
8. **操作结果可见**：RAW 中未进入精选版的标题保留并加删除线；删除线表达数据处理结果，不是装饰。
9. **状态先于装饰**：Dashboard、来源卡、时间线都优先回答“现在怎样、哪里异常、下一步是什么”。
10. **真实时间**：发布时间、首次抓取时间必须明确区分；不为了好看伪造新鲜度。

## 独特性来自哪里

这个可复用包没有加载 shadcn、Material UI、Ant Design、Tailwind UI、第三方字体或现成 Dashboard 模板。它的源码是围绕 Signal Desk 的来源监控、RAW→AI 门禁、时间线与任务台重新提炼的；这说明它不是某个通用 UI 包的换皮，但不构成法律意义上的独创性或排他性证明。

不过，编辑排版、工业控制台、新粗野主义、米白纸张和荧光强调色本身都是公共设计语言。单独使用其中一项并不独特；**独特性来自它们的固定组合，以及与产品逻辑绑定的组件**：

- 黑色粘顶操作台 + 3px 酸绿底线；
- 超大实心标题 + 第二行描边标题；
- 时间线酸绿节点；
- RAW 排除标题的红色删除线；
- 原产品中的 50 家来源墙和四维健康状态（属于产品适配层，本精简包不携带业务数据）；
- 中文编辑部式命名，而非通用 SaaS 文案。

如果希望进一步建立可识别、可保护的品牌资产，下一步应加入定制字标、专属图标/动效、固定插图语法和经过授权的品牌字体。

## 如何复用

1. 引入 `signal-desk-ui-kit.css`。
2. 在应用最外层添加 `class="sd"`，以避免污染其他项目。
3. 复用组件类：`sd-console`、`sd-hero`、`sd-dashboard`、`sd-controls`、`sd-stream`、`sd-card`、`sd-badge`。
4. 优先修改 CSS token 完成品牌换色；若品牌语义不同，再调整对应的状态组件，不要机械复用颜色含义。

```html
<link rel="stylesheet" href="signal-desk-ui-kit.css">
<main class="sd">
  <div class="sd-frame">
    <section class="sd-dashboard">…</section>
  </div>
</main>
```

换色示例：

```css
.my-project {
  --sd-paper: #f6f2ea;
  --sd-ink: #172126;
  --sd-acid: #b7ff43;
  --sd-alert: #e24b35;
}
```

## 复用时不要做的事

- 不要加入玻璃拟态、紫蓝渐变和大面积柔和阴影；那会变成通用“AI 网站”。
- 不要把所有状态都涂成酸绿；酸绿只有在稀缺时才像信号。
- 不要用圆角卡片替代信息网格。
- 不要为了“呼吸感”把新闻行拉得很高；密度是这套系统的核心能力。
- 不要只复制颜色。必须连同层级、对齐、状态语义和文案纪律一起复用。
- 不要把删除线当作通用“删除”样式；这里只表示“数据仍保留，但未进入下一级交付”。

## 展示页边界

`signal-desk-ui-kit.html` 是零依赖的视觉组件样本，按钮、筛选器和示例链接不包含业务逻辑。真实项目应接入自己的路由、数据、键盘焦点和加载/错误状态。

## 文件

- `signal-desk-ui-kit.css`：无依赖、带 `sd-` 前缀的可移植组件样式。
- `signal-desk-ui-kit.html`：可直接打开的组件展示页。
- 本文：设计原则、独特性边界和迁移方式。
