1. **规模与口径**：全球数据中心约 103GW（IT 容量，2025），2030 年预测约 200GW——但容量（GW）、用电（TWh）、投资（美元）、需求模型是四种口径永不混加；只有通电投运（L8+）才是当期供给，规划容量必须乘以历史转化率。（M01）
2. **瓶颈是动态关键路径**：2026 年新立项大项目的第一约束已从 GPU 转向"某个日期可兑现的电力+并网"；ERCOT 225GW 申请队列是热度不是容量，须经四轮折减。（M04 / M15）
3. **设备交期是全行业最诚实的温度计**：配电变压器交期 1–2 年以上、大型变压器最高 4 年；GE Vernova 燃机签约 ≥125GW 而年产能仅约 20GW——规则改革压缩行政等待，但造不出设备。（M09 / M04）
4. **散热的常态是混合架构**：冷板带走主热、空气处理余热；MW 级 CDU 已成量产标准品，竞争从单设备转向"芯片到室外"整链交付，并购正在重组供应链。（M08）
5. **供给双轨与期限错配**：超大规模厂自建+租赁并行扩张；Neocloud 以合同融资高速放大——CoreWeave 2026Q2 活跃功率 1.5GW、积压 1,040 亿美元、债务约 350 亿，收入翻倍与亏损扩大并行，期限错配（建筑 15–40 年 / GPU 3–6 年 / 合同 5–15 年）是资金链核心脆弱点。（M02 / M11）
6. **需求侧经济学当前健康**：旗舰模型牌价稳定在 $12–50/M 输出窄带，真实降价发生在次旗舰档与固定性能口径（年降 9–900 倍）；Agent 负载+缓存下实现价远低于牌价，但成本降得更快，头部实验室推理毛利从 <40% 升至 >70%——周期顶部信号（毛利转负）距离尚远。（M12）
7. **收入与承诺的缺口是最大宏观风险**：OpenAI 年化约 $40B、Anthropic 约 $47B，对应 $600B–$1.4T 级算力承诺，收入/承诺比仅 0.23–0.33；循环交易（芯片商投资客户、云厂预付）会放大任何断裂的传导。（M12 / M03 / M11）
8. **全球格局是分层而非单一中心**：训练容量向电力型市场集中，推理、合规与互联留在客户型市场；美国卡并网、欧洲卡规划、新加坡卡配额、中东卡兑现、中国卡先进芯片与利用率——五大区域第一瓶颈各不相同。（M05 / M15 / M14）
9. **物理 GW ≠ 经济 GW**：通电容量到有效算力之间隔着利用率、调度与软件栈；同样 1GW，利用率 30% 与 70% 是两个行业——有效算力转化率是被多数研究忽略的第二战场。（M13）
10. **三情景与切换触发器**：基准 = IEA 945TWh 与 McKinsey 219GW 双锚（2030），乐观/压力 ±15%–25% 为本研究假设非机构指引；转压力情景的组合信号 = 推理毛利转负 + GPU 现货长约倒挂 + 算力 ABS 利差走阔同季出现。（M15）
