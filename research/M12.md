## M12-F1 旗舰模型牌价稳定在 $12–$50/M 输出的窄带，降价发生在次旗舰档与"固定性能"口径 {new}
- **状态**：current ｜ **修订**：2026-08-14 ｜ **触发器**：indicators:token_price_flagship、periodic:90d
- **结论**：截至 2026-08，三家旗舰 API 定价（$/M tokens，输入/输出）：OpenAI GPT-5.6 Sol $5/$30（长上下文 $10/$45）、Anthropic Claude Fable 5 $10/$50（Opus 5 $5/$25、Sonnet 5 $2/$10）、Google Gemini 3.1 Pro Preview $2/$12（>200k 提示 $4/$18）。旗舰牌价并未持续崩塌——各家把最强模型稳定钉在高价档；真实的降价发生在两处：**次旗舰/走量档**（OpenAI 2026-07-30 将 Terra 降价 20%、Luna 降价 80%；Anthropic 取消 Sonnet 5 原定 2026-09-01 从 $2/$10 回调 $3/$15 的涨价，把促销价固化为常态价；Google Gemini 3.7 Flash 以半价 $0.75/$3.75 促销至 2026 年底），以及**固定性能口径**——达到既定能力水平（如 GPT-4 级 GPQA 表现）的价格按 Epoch AI 测算以每年 9x–900x 的速度下降（六项基准、近三年数据，最快降幅集中在最近一年）。
- **论证**：
  - 三家的产品阶梯收敛为同构三层（旗舰 / 均衡 / 走量），价格带分别约 $30–50、$10–12、$1.2–2.5 每 M 输出；竞争压力集中在中低两层，旗舰层靠能力代差维持定价权。

  - 因此监测 token_price_flagship 必须固定"当期旗舰"口径逐月记录牌价，同时定期用 Epoch 固定性能曲线校准跨代际真实降幅；只看其中一条线都会误判。

## M12-F2 Agent 负载结构 + 缓存折扣使实现价格远低于牌价，但成本降得更快，头部 lab 推理毛利不降反升 {new}
- **状态**：current ｜ **修订**：2026-08-14 ｜ **触发器**：indicators:inference_unit_margin、periodic:90d
- **结论**：SemiAnalysis（2026-05）推算 Claude Opus 4.7 在 agentic 负载下的**真实混合价格约 $0.99/M tokens**，而牌价为 $5/$25——因为 agent 任务输入/输出比约 300:1 且缓存命中率 90%+，绝大多数 tokens 落在 $0.50/M 的缓存读取档。即便实现价格如此之低，同期头部 lab 的**推理毛利率仍从 <40% 升至 >70%**：硬件换代（Hopper→Blackwell）加软件优化（同硬件吞吐提升至 14x）使单 token 生产成本下降快于价格下降。推理单位经济学当前为正且在扩张，inference_unit_margin 首个方向性读数为"健康、未触红"。
- **论证**：
  - 这回答了本模块"毛利还有多厚"的核心问题：降价不是亏本获客，而是成本曲线陡降下的让利，价格战尚未侵蚀到毛利为负的区间。
  - 毛利>70% 仅指推理设施边际口径；训练、研发、免费用户补贴计入后头部 lab 整体仍大幅亏损（OpenAI 媒体报道口径年亏损百亿级），"推理赚钱"与"公司赚钱"是两件事。
  - 该结论对 200GW 叙事的含义：只要推理毛利为正，token 需求增长就直接转化为算力采购能力；inference_unit_margin 转负才是需求侧周期顶部信号，当前距离尚远。
- **证据**：
  - [S3/research] SemiAnalysis《AI Value Capture — The Shift To Model Labs》：Opus 4.7 agentic 混合价 $0.99/M、300:1 输入输出比、缓存命中 90%+、推理毛利 <40%→>70%、同硬件 14x 吞吐 — https://newsletter.semianalysis.com/p/ai-value-capture-the-shift-to-model
  - [S2/company] Anthropic 定价页（缓存命中 = 0.1x 基础输入价，即 Opus 档 $0.50/M 的依据）— https://platform.claude.com/docs/en/about-claude/pricing
  - [数据层] companies:anthropic ｜ companies:openai ｜ prices:gpu-hourly-h100-spot@2026-07-31
- **口径提醒**：$0.99/M 与毛利区间均为 SemiAnalysis 第三方推算，非公司披露，依赖其负载结构假设（输入输出比、缓存命中率随产品形态变化会漂移）；"推理毛利"只计推理边际成本，不含训练与研发摊销，不能引申为"AI lab 已盈利"；混合价与牌价是两种口径，做收入测算用混合价、做定价策略分析用牌价。
- **待办**：inference_unit_margin 数值化落库（需固定一套硬件成本+电价+吞吐假设的推算模板）；跟踪 SemiAnalysis InferenceMAX/InferenceX 基准更新。

## M12-F4 企业 AI 支出已成真实预算线：2025 年 $37B、一年 3.2 倍，但生产级 agent 部署仍是少数 {new}
- **状态**：current ｜ **修订**：2026-08-14 ｜ **触发器**：indicators:ai_revenue_capex_ratio、periodic:90d
- **结论**：Menlo Ventures 调查（约 500 名美国企业决策者，2025-11）：企业 generative AI 支出 2023 年 $1.7B → 2024 年 $11.5B → 2025 年 **$370 亿**（一年 3.2x），已占全球 SaaS 市场约 6%，为软件史上扩张最快的品类。结构上应用层 $19B、基础模型 API $12.5B、模型训练 $4B；编码工具（$4B）与医疗垂直（$1.5B）是最集中的落点。但**只有 16% 的企业部署（初创为 27%）够得上真正的 agent**，多数仍是单次模型调用的基础工作流——渗透是真实的，深度仍在早期。
- **论证**：
  - $12.5B 的模型 API 支出与 F3 的 lab 收入形成交叉验证：企业 API 是收入的真实构成之一，而非全靠消费者订阅。
  - "支出 3.2x"与"仅 16% 真 agent"合读：当前支出主要由浅层用例驱动，若 agent 化率提升，按 F5 的 token 乘数逻辑，支出上行空间远未见顶；反之若 3.2x 增速失速而 agent 化率仍停在低位，则是需求侧见顶的早期信号。
  - 对 M15 情景的意义：企业支出增速（年度）+ agent 化率（年度）是比物理层空置率领先约一年以上的需求温度计输入。
- **证据**：
  - [S3/research] Menlo Ventures《2025: The State of Generative AI in the Enterprise》：$1.7B/$11.5B/$37B、6% of SaaS、API $12.5B、16%/27% agent 部署率、调查方法 — https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise/

## M12-F5 Token 消耗量超指数放大：Google 单家月处理量两年 330 倍，"量补价"已是事实而非假说 {new}
- **状态**：current ｜ **修订**：2026-08-14 ｜ **触发器**：indicators:token_price_flagship、periodic:90d
- **结论**：Google I/O 2026 主旨演讲（Pichai）：Google 全线产品月处理 token 量从 2024-05 的 **9.7 万亿** → 2025-05 的 **约 480 万亿** → 2026-05 的 **超 3.2 千万亿（quadrillion）**，两年约 330x、最近一年 7x。驱动结构正从单轮对话转向 agent 负载：SemiAnalysis 测得 agentic 任务输入/输出比约 300:1，单任务 token 消耗比单轮对话高数个量级。价格（固定性能口径年降 9x–900x，F1）与量（单家年增 7x）对冲后，行业 token 收入仍在膨胀（F3 两家 lab 收入一年 2x–47x 为旁证）——**"以量补价"目前成立**，这是 200GW 叙事在需求侧的核心支撑，也是最需要持续证伪的假设。
- **论证**：
  - 7x 年增速与 F4"仅 16% 真 agent 部署"合读：若企业 agent 化率从 16% 走向多数，token 量仍有结构性放大空间；反之 token 量增速跌破价格降速（量增 < 价降）之时，就是行业收入见顶的算术临界点——该差值应成为本模块季度温度计的显性输出。
  - Google 数字是唯一由巨头连续三年可比披露的 token 量序列，作为行业量能代理指标最合适；但它是"全产品含内部"口径，方向可用、绝对值不能当行业商业化规模。
- **证据**：
  - [S2/company] Google 官方博客 I/O 2026 keynote 文字稿：9.7T（两年前）→ 约 480T（一年前）→ 3.2 quadrillion+/月、7x Y/Y — https://blog.google/innovation-and-ai/sundar-pichai-io-2026/
  - [S3/research] SemiAnalysis：agentic 负载 300:1 输入输出比 — https://newsletter.semianalysis.com/p/ai-value-capture-the-shift-to-model
  - [S3/research] Menlo Ventures：16%/27% agent 部署率（放大空间论证）— https://menlovc.com/perspective/2025-the-state-of-generative-ai-in-the-enterprise/
  - [数据层] companies:alphabet-google
- **口径提醒**：3.2 quadrillion 含 Search AI Overviews、YouTube、Workspace 等全部内部与免费面，**不是**商业化 API token 量，token 量 ≠ 收入；不同厂商 tokenizer 不同，跨家 token 量不可相加或直接对比；"量补价成立"是当前时点判断，其证伪条件（量增速 < 固定性能价格降速）必须随每季温度计重算。
- **待办**：寻找 OpenAI/Anthropic/OpenRouter 可比的 token 量时间序列（目前无连续披露）；单 agent 任务 token 消耗的实测基准未建。

## M12-F7 前沿实验室的估值倍数有两个口径陷阱，两个都会让倍数看起来更便宜 {new}

- **状态**：current ｜ **修订**：2026-08-17 ｜ **触发器**：indicators:valuation_to_arr、entity:openai、entity:anthropic、periodic:90d
- **结论**：OpenAI 估值/ARR 为 **42x**（8,400 亿 ÷ 200 亿）、Anthropic **27.1x**（3,800 亿 ÷ 140 亿）。
  这两个数同口径、可比。但把它们与上市公司 P/S 并列会**双向失真**，因为两个口径陷阱**同向**：
  1. **分子是一级市场 post-money 估值，不是可交易市值**——含优先清算权等条款，
     同样的企业价值在一级市场标价更高；
  2. **分母是 ARR（年化运行率 = 某月收入 × 12），不是会计确认收入**——
     增长期公司的 ARR 显著高于当年实际收入。

  **两个偏差都让倍数显得更小**：分母被年化放大、分子虽偏高但被放大的分母更多地抵消。
  用会计收入重算，倍数会明显高于 42x 与 27.1x。**因此这两个数不能当作「比上市公司贵多少」的答案。**
- **论证**：
  - 为什么这类错最容易犯：**42x 和上市公司的 P/S 长得一模一样**——都是一个倍数、都有出处。
    与「模型假设 vs 实测」（M15-F11）是同型问题的不同形态：**形状相同、生成机制不同。**
    本库因此在 `valuation_to_arr` 上把 `valuation_basis` 与 `revenue_basis` **两个口径都设为必填维度**，
    缺一个就无法判断这个倍数能和什么比。
  - Anthropic 的 ARR（140 亿）是报告直接列示；**OpenAI 的 ARR（200 亿）是我们从 8,400÷42 反推的**，
    精度受 42 这个两位有效数字限制，**不应视为精确值**（已标 `derived` 并写算式）。
  - 报告称 OpenAI 的溢价在 1,100 亿美元轮之后「反转」——即此前 OpenAI 相对 Anthropic 的倍数溢价方向变了。
    **这条只是报告的表述，本库尚无第二个时点的倍数可验证，不作为结论。**
- **证据**：
