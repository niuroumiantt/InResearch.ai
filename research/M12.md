## 开放问题（待首版研究）

1. **每百万 token 价格（旗舰/中档/开源自托管）的下降曲线与降幅节奏？**——需要：OpenAI/Anthropic/Google 官方 API 定价页的历史快照（Wayback Machine 回溯）+ 月度抓取入 prices 表；开源自托管口径需配合 GPU 租价（依赖 M13 的 gpu_hourly_rate_spot）折算；落库为 indicators:token_price_flagship。
2. **推理单位成本（$/M token）的硬件+能耗分解，毛利空间还有多厚？**——需要：主流模型的公开吞吐基准（token/s/GPU）、GPU 时租与折旧假设、电价假设；SemiAnalysis 类第三方拆解作交叉验证；落库为 indicators:inference_unit_margin（转负触红）。
3. **头部 AI 公司（OpenAI/Anthropic 等）收入增速 vs 算力承诺支出的比值走势？**——需要：媒体披露的 ARR 数据（The Information/Reuters 等，S3–S4 级需标注口径）、已公告算力承诺金额（合同事实本身归 M03，本模块取比值）；落库为 indicators:ai_revenue_capex_ratio。
4. **企业 AI 支出的真实渗透率与续约率（不是试点，是生产负载）？**——需要：Ramp/Menlo Ventures 类企业支出调查、云厂商财报中 AI 收入口径披露、渠道信息（企业客户续约与扩容行为）。
5. **"单位算力收入 / 单位算力全成本"比值：>1 的负载占比在扩大还是缩小？**——需要：上述 1–3 项数据齐备后的合成计算框架；负载结构估算（训练 vs 推理 vs 内部研发）；此为本模块季度"需求经济学温度计"的核心输出。
6. **Agent/长推理负载对 token 消耗量的乘数效应有多大（量能否补价）？**——需要：OpenRouter 等聚合平台的公开用量数据、模型厂商披露的 token 处理量时间序列、单任务 token 消耗的实测基准（agent 任务 vs 单轮对话）。
